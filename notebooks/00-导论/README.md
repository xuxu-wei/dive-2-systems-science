# 导论：走进系统科学

跑步结束以后，身体为什么还要继续恢复？一处物质读数下降，能否说明它已经离开了整个身体？人数和联系数相同的两组人，会有相同的消息传播过程吗？

导论从这些问题开始。我们先把组成、联系和环境放在一起，再认识不同方法为什么出现，最后用六个人的消息传播完成一次可以手算和运行的计算实验。三节连起来，帮助你理解系统科学怎样从现象走向有依据的解释。

| 阅读顺序 | Notebook | 本节回答的问题 |
|---|---|---|
| 导论·1 | [从生命现象认识系统](01-从生命现象认识系统.ipynb) | 怎样把恢复过程中的组成、联系与环境放在一起研究？ |
| 导论·2 | [系统科学关心什么，如何发展](02-系统科学关心什么如何发展.ipynb) | 理解读数、预测变化与选择行动，分别需要哪些方法？ |
| 导论·3 | [从系统问题走向计算与证据](03-从系统问题走向计算与证据.ipynb) | 怎样把传播规则算清楚，再用一个新起点检验解释？ |

每节有三道选择题，独立作答后可在网页查看逐项解析。自测帮助你发现需要回看的概念；完成阅读后即可进入[第 1 篇：看见系统](../01-看见系统/README.md)，进一步学习研究范围、测量关系、收支和反馈。
