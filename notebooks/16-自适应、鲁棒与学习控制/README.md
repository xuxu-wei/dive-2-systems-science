# 第 16 篇：自适应、鲁棒与学习控制

前面的控制设计使用了给定模型。如果恢复速度并不确定，或者执行器只能提供有限输入，原来的下降论证还覆盖哪些情况？如果边运行边估计参数，应该先更新估计还是先决定输入？随机扰动、通信延迟和有限训练经验又会留下哪些问题？

本篇先从一个非线性偏差恢复模型推导反馈，把请求输入和实际输入分开。随后在两个矩阵之间的模型集合上寻找共同的下降依据，再将递推参数估计接入控制，沿观测到达的次序说明每一步使用的信息。

后半篇把同样的问题放到随机路径、三个相互通信的节点和有限决策模型中。最后用学习模型选择受约束动作：先筛选预测可行的候选，再检查实际结果，并在同一组场景中分别记录预测误差、输入成本和失败。

阅读时先确认已知量、可用观测、输入限制和要回答的问题，手算一两步后对照代码及实验输出。十四节正文与篇末综合按下表展开：
