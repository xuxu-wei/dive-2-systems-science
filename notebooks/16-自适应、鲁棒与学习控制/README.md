# 第 16 篇：自适应、鲁棒与学习控制

模型系数变化、输入受限、观测晚到时，原来的调节方法会怎样变化？本篇从非线性反馈与实际限幅开始，依次研究共同稳定条件、在线辨识、随机恢复、局部通信和有限经验学习，最后用预测模型筛选受约束动作，并比较实际结果。
