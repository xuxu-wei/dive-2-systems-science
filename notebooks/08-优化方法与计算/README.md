# 第 8 篇：优化方法与计算

同一组读数，可以由不同系数组合预测；同一个下降方向，步长不同也会收敛或发散。这一篇从“想改善哪个量、可以改变哪些变量、怎样比较两次尝试”开始，把拟合与决策写成能计算、能解释的优化问题。

先用四行物质变化记录比较候选系数，按行求出偏导，再从误差倍率理解步长。随后用近乎相同的候选列引出岭与L1惩罚，留下独立数据评价预测。最后换成两路输入配置，先检查最低需求，再用乘子和边界计算寻找允许范围内的最好方案。

承接第3篇的线性代数、第6篇的拟合与独立检验。本篇十节与篇末综合都先说明列表位置、尺度和当前未知量，再连接手算、公式、代码与结果。
