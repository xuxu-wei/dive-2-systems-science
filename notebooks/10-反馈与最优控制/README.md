# 第 10 篇：反馈与最优控制

温度低于目标，该请求多少加热？请求发出后，执行器又实际给出多少？这一篇从一次可以手算的 PI更新开始，沿着测量、误差、输入和下一状态，建立反馈控制的时间顺序。

先比较恒定扰动下的比例与积分作用，再看两个响应环节的特征根和延迟相位。随后改变执行器与传感器位置，解释状态为何可以控制或恢复；用估计接入反馈后，从一笔当前和终端成本推导 Bellman、LQR与带硬约束的有限输入 MPC。最后在相同外部场景中比较误差、实际输入与失败，按独立场景保留配对关系。

承接第6篇的动态模型、第7篇的状态估计和第8篇的优化。新符号、时刻和量纲变化在公式旁说明；每节保留手算、核心代码、实验和与其对应的核对。
