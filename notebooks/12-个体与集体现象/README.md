# 第 12 篇：个体与集体现象

一排格子只读取左右邻居，怎样逐渐形成整行图案？两类个体各占一半，成团与交错为什么会获得不同收益？本篇从这些可手算的局部问题进入，逐步连接群体频率、有限抽样和连续空间分布。

承接第11篇的邻域、守恒交换与随机传播，先学习格子更新时序，再按相遇收益推导频率变化，随后加入选择、变异和有限后代抽样。空间部分从邻格交换进入反应扩散，最后用不同排列检验宏观平均保留了哪些信息。导数、概率和矩阵沿用前篇基础。

网页完成概念、手算、推导与结果解释，11份 Notebook 提供可修改的独立实验。按下表顺序阅读，再从正文进入相关实验、可视化或练习。
