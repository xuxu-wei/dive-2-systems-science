# 第 13 篇：临界变化与韧性

同一条群体规则，50个与800个个体为什么会产生不同波动？一个节点受损以后，失效会停在起点还是沿联系继续？两种模型在原平衡附近恢复得一样快，为什么同样的较大扰动仍会走向不同结果？

本篇承接第12篇的局部更新、有限抽样与宏观描述。先用有符号平均与重复轨迹研究有限规模，再手算网络级联和剩余连通规模；随后比较局部恢复与吸引域，并用噪声对照检查预警指标。最后回到两个密度相同的四格环，讨论粗粒化的信息损失，以及条件和尺度改变怎样影响判断。

网页完成概念、手算、推导与结果解释，九份 Notebook 提供可修改的独立实验。按下表顺序阅读，再从正文进入相关实验、可视化或练习。
