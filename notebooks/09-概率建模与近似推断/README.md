# 第 9 篇：概率建模与近似推断

同一个人反复测量，读数会因噪声变化，未知偏差却在本次实验中固定。多测几次究竟减少哪一种不确定性？这一篇从两次读数开始，把参数后验与未来读数预测分开，再学习积分难算时的采样与分布近似。

先手算高斯精度与Gamma曲率，再用两状态概率流建立采样规则。随后从相关参数和四种细胞状态看独立近似的限制，用归组概率与平滑矩连接隐变量学习。最后先给出预测，再用新读数检查区间和模型；每一步都说明已知条件、平均对象与计算预算。

承接第5篇概率与条件期望、第7篇状态估计，以及第8篇优化。新增积分、求和和迭代符号在使用前解释，完整算法与独立参照均在Notebook中展开。
