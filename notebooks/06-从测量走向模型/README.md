# 第 6 篇：从测量走向模型

同一段节律，每秒测一次和每秒测四次，为什么会给出不同的印象？把读数取平均以后，曲线变平了，峰值却可能晚到。建立动态模型之前，我们先追问仪器记录了什么，以及采样和处理怎样改变了能够看见的变化。

接下来，把单室收支写成卷积、变换与离散递推，再反过来用观测估计参数。我们从几个可以手算的点开始，逐步检查误差假设、输入变化和数据划分，最后让模型在新读数到来前给出预测。前篇的条件期望在这里用于说明：已知历史和输入后，尚未发生的扰动如何影响平均预测。

学习时承接第 2 篇的微积分与数值模拟、第 3 篇的线性代数和复数表示，以及第 5 篇的概率与噪声。按下表依次打开 Notebook，探索页用于改变条件并对照结果。
