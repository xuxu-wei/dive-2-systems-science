# 第 1 篇：看见系统

一条下降的温度曲线，能告诉我们身体里的每一处都在降温吗？某种物质离开血液以后，是被清除了，还是转移到了组织？调节器一直在纠正偏差，为什么还会越过目标？本篇从这些问题出发，学习怎样确定研究范围、解释读数、计算收支，并检验模型给出的预测。

推荐先读[导论：走进系统科学](../00-导论/README.md)。导论中的六人传播实验让我们看到，同样的人数和联系数可以产生不同的传播过程；现在进一步追问：要解释一种变化，需要保留哪些量、写出哪些规则、设计什么样的新观察？

按以下顺序学习。每节包含完整讲解、实验与练习；配套入口位于各节正文中。

| 章节 | Notebook | 核心问题 |
|---|---|---|
| 1.1.1 | [边界、状态与观测](01-从生理现象提出系统问题/01-边界状态与观测.ipynb) | 选择要研究的对象，分清被测温度与仪器读数。 |
| 1.1.2 | [单位、量纲与时间序列](01-从生理现象提出系统问题/02-单位量纲与时间序列.ipynb) | 换算同一份记录的时间坐标，分清总量与浓度，说明连线没有增添测量。 |
| 1.2.1 | [一段时间的物质收支](02-存量流量与守恒/01-一段时间的物质收支.ipynb) | 先算每段进入和离开多少，再从上一段留下的量继续记账。 |
| 1.2.2 | [内部交换与整体守恒](02-存量流量与守恒/02-内部交换与整体守恒.ipynb) | 分别算血液和组织中的量，再把两本账相加，说明内部转移为何不改变两处总量。 |

| 篇末综合 | [系统边界与实验设计](05-篇末综合/01-系统边界与实验设计.ipynb) | 在细胞计数、温度调节和物质清除三个问题中，结合研究范围、收支和预测检查解释。 |
