# 第 15 篇：可微分建模与机制融合

一个网络算出了响应，这个数怎样进入状态预测？训练误差下降了，怎样核对调整参数所用的梯度？若保留已知清除项，再学习一个修正，观测又能分清它们各自的作用吗？

本篇从一个输入、一个输出的平滑函数开始。先算预测，再形成损失，沿依赖关系求参数导数。随后将函数用于固定间隔的下一状态，比较每步获得真实状态与从初值自由递推；再将可学习函数放入连续右端，把求解误差和参数灵敏度连起来。

后半篇直接用可微函数表示候选解，分别检查数据、方程、初值和边界。最后回到总量收支，用新输入比较机制基线与混合修正，再以等价参数解释预测准确为什么仍可能留下机制混淆。

阅读时先确认输入和输出的单位、下标与排列，手算一两步，再对照代码和原实验结果。十节正文与篇末综合按下表展开：
