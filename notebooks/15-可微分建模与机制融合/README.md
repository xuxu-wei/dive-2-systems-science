# 第 15 篇：可微分建模与机制融合

一个预测由哪些参数决定，误差又怎样沿计算过程传回？本篇从单神经元的响应与损失开始，逐步进入离散动态、连续方程的灵敏度、方程与初边值损失，最后把可学习修正放回总量收支，比较新输入预测与参数辨识所需的信息。
