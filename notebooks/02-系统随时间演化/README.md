# 第 2 篇：系统随时间演化

本目录提供网页正文的动手实验：运行递推、差商、矩形累积与一阶收支模型，再修改参数比较结果。完整概念讲解、推导及习题从[第 2 篇网页目录](http://127.0.0.1:8000/parts/02-系统随时间演化/)进入。

Notebook 按下表顺序运行，每本均可从全新内核执行。总量以 U、时间以 T 计；各实验另有说明的变量按对应单位使用。

| 小节 | 实验 Notebook | 实验内容 |
|---|---|---|
| 2.1.1 | [递推关系、累积与固定点](01-用递推描述增长与清除/01-从逐步变化到递推规则.ipynb) | 比较无补入计数与持续补入物质池的逐步变化，检查迭代、闭式和累计变化是否一致。 |
| 2.1.2 | [流率、时长与离散收支](01-用递推描述增长与清除/02-让时间进入收支更新.ipynb) | 把流入速率和消除速率乘以实际时长，比较不同步长下的收支更新。 |
| 2.2.1 | [平均变化率、极限与导数](02-变化率与累积微积分入口/01-从平均变化到导数.ipynb) | 比较割线与切线，观察差商的近似误差及浮点相减误差。 |
| 2.2.2 | [矩形和、定积分与累积](02-变化率与累积微积分入口/02-从矩形累积到定积分.ipynb) | 用左端矩形和估计总流入，比较累计流入与含初值的池内总量。 |
| 2.2.3 | [指数、自然对数与链式法则](02-变化率与累积微积分入口/03-指数对数与链式法则.ipynb) | 观察连续比例变化的指数曲线，并用差商检查链式法则给出的导数。 |
| 2.3.1 | [一阶微分方程与初值问题](03-连续时间与一阶微分方程/01-从收支率到一阶初值问题.ipynb) | 比较欧拉更新与一阶收支方程的连续解，并检查初值和方程残差。 |
| 2.3.2 | [平衡与恢复时间尺度](03-连续时间与一阶微分方程/02-平衡位置与靠近速度.ipynb) | 在平衡总量相同的情况下比较恢复速度，并核对偏离半衰时间和目标比例到达时间。 |
| 2.4.1 | [欧拉误差与网格收敛](04-数值模拟误差与迁移/01-误差与网格细化.ipynb) | 用解析参考测量欧拉误差，比较步长减半后的误差比例与观测收敛阶。 |
| 2.4.2 | [数值稳定性与非负性](04-数值模拟误差与迁移/02-稳定性与非负性不是一回事.ipynb) | 比较数值偏离的衰减、正负交替和放大，并单独检查总量非负性。 |
| 2.4.3 | [输入跳变与分段模拟](04-数值模拟误差与迁移/03-在输入跳变处分段计算.ipynb) | 让时间步在输入切换点结束，再按实际时长接续欧拉计算与解析参考。 |
| 篇末综合 | [分段输入的峰值与过程约束](05-篇末综合/01-等总量输入的不同过程.ipynb) | 比较总流入均为 4 U 的三种时间安排，核对峰值、终值、累计清除和数值误差。 |
