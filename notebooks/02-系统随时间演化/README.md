# 第 2 篇：系统随时间演化

同样多的物质进入系统，怎样安排流入时间，会改变系统中的总量变化吗？要回答这个问题，我们先逐段计算流入与清除，再学习怎样描述每个时刻的变化，最后比较连续解与数值计算。

本篇沿用第 1 篇的物质收支，从几次手算引入所需数学：递推、导数和积分、指数与对数，随后求解一阶微分方程。篇末回到等总量输入，用峰值、终值和累计收支解释不同方案。按下表顺序阅读，每节末尾可进入对应练习。

| 小节 | Notebook | 学习重点 |
|---|---|---|
| 2.1.1 | [从逐步变化到递推规则](01-用递推描述增长与清除/01-从逐步变化到递推规则.ipynb) | 从几次手算写出递推规则，说明下标与更新次数，求出固定点并核对累计变化。 |
| 2.1.2 | [让时间进入收支更新](01-用递推描述增长与清除/02-让时间进入收支更新.ipynb) | 用速率乘实际时长计算收支，分清每步比例与清除系数，解释总量列表和累计流入。 |
| 2.2.1 | [从平均变化到导数](02-变化率与累积微积分入口/01-从平均变化到导数.ipynb) | 从区间平均变化率推到导数，用代数、切线和浮点计算解释三者的联系与差别。 |
| 2.2.2 | [从矩形累积到定积分](02-变化率与累积微积分入口/02-从矩形累积到定积分.ipynb) | 用短段流入量的和认识定积分，再从累计净变化和初值恢复总量。 |
| 2.2.3 | [指数对数与链式法则](02-变化率与累积微积分入口/03-指数对数与链式法则.ipynb) | 用比例变化认识指数函数，逐层求衰减曲线的导数，再用自然对数反求指数。 |
| 2.3.1 | [从收支率到一阶初值问题](03-连续时间与一阶微分方程/01-从收支率到一阶初值问题.ipynb) | 由持续收支建立一阶初值问题，求出恒定输入解并核对方程、初值和零清除情形。 |
| 2.3.2 | [平衡位置与靠近速度](03-连续时间与一阶微分方程/02-平衡位置与靠近速度.ipynb) | 保持平衡总量不变，比较偏离的衰减速度；从零起点求达到目标比例的时间。 |
| 2.4.1 | [误差与网格细化](04-数值模拟误差与迁移/01-误差与网格细化.ipynb) | 从一步近似解释全程误差，在同一初值问题上缩短步长并计算误差缩小的比例。 |
| 2.4.2 | [稳定性与非负性不是一回事](04-数值模拟误差与迁移/02-稳定性与非负性不是一回事.ipynb) | 用每步偏差乘数判断衰减与振荡，另行检查总量非负条件和实际误差。 |
| 2.4.3 | [在输入跳变处分段计算](04-数值模拟误差与迁移/03-在输入跳变处分段计算.ipynb) | 让计算停在流入速率改变的时刻，用实际时长分别接续欧拉结果与解析参考。 |
| 篇末综合 | [等总量输入的不同过程](05-篇末综合/01-等总量输入的不同过程.ipynb) | 比较等总量输入的时间安排，核对累计收支、峰值、终值和误差，再筛选符合上限的方案。 |
