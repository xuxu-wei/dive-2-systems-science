# 第 11 篇：网络上的系统

四个细胞通过三条通道交换物质，怎样记录谁与谁相连？物质经过几条边才能到达另一端？本篇从图结构出发，依次研究守恒扩散、接触传播与耦合节律。网页完成概念、推导和结果解释，9份 Notebook 提供可修改的独立实验。

第10篇通过输入、测量和反馈研究多变量系统；本篇进一步用网络表示变量之间的连接。先修为第3篇的矩阵与多变量动态、第4篇的节律，以及第5篇的概率与随机过程。按下表阅读，再从正文打开相关实验、可视化或练习。
