# 第 11 篇：网络上的系统

四个细胞通过三条通道交换物质，怎样记录谁与谁相连？物质经过几条边才能到达另一端？本篇先从四节点路径进入，再给连接加上交换、传播与相位耦合规则。

先把边表展开成矩阵，手数度、分量和路径；再沿一条边的一减一加推导全网守恒，说明容积与平衡。随后按旧状态跟算同步感染和恢复，用分层重复比较连接结构；最后把相位放到单位圆上，分别解释全局集中与一段时间内的频率接近。

承接第3篇多变量动态、第4篇节律与第5篇随机过程。节点编号、边表数对和求和下标在使用时说明；物质总量、浓度、每步概率与角频率保持各自单位。
