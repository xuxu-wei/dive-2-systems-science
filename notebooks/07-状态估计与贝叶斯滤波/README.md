# 第 7 篇：状态估计与贝叶斯滤波

第一室读数下降，物质是转移到了第二室，还是仪器把数值报低了？只测一室，怎样推断另一室现在的状态？第6篇用读数估计动态规则；这一篇把规则视为已知，转而追踪随时间变化、却没有被完整测到的状态。

我们先手算一次两室转移和一次隐藏状态更新，再把“预测、取得读数、修正”接成循环。线性高斯模型可以准确计算条件均值与协方差；平方传感器会产生正负两侧解释，引出局部近似、代表点和粒子。最后，等整段记录到齐，再回看缺测期间，说明滤波与平滑为何得到不同结果。

承接第3篇的状态空间与线性代数、第5篇的概率与条件期望，以及第6篇的观测时间顺序。按下表学习；每次比较估计，都先确认状态列表的顺序和已经取得的读数。
