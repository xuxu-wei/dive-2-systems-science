# 第 4 篇：非线性动态行为

本目录提供网页讲授的独立实验：从平衡和扰动进入多稳态、极限环、分岔、敏感性与稳定性，再用 Lorenz 方程比较三维轨迹、返回和切向增长。完整讲解与练习从[第 4 篇导览](http://127.0.0.1:8000/parts/04-非线性动态行为/)进入。

每本可从新内核执行；先查看模型与单位，再修改参数和运行对照。连续模型使用缩放时间，离散映射按代次更新。
