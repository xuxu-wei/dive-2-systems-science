# 第 4 篇：非线性动态行为

同样的条件，为什么一次扰动会让系统走向另一种长期状态？持续振荡为什么能在撤去外部输入后保留下来？第 3 篇用局部近似描述平衡附近的变化，本篇从这些近似之外的问题出发，依次比较多稳态、周期运动和对初值敏感的轨迹。

我们先在一个活动开关中手算变化方向，再让二维振子恢复半径；随后逐代更新种群比例，追踪邻近初值怎样分离。最后进入 Lorenz 系统，将有界轨迹、截面交点和扰动增长放在一起解释。每次计算都先说明变量、比较对象和观察时间，读完推导再用代码检查。
