# 第 3 篇：多变量相互作用

同样多的物质，留在血液里还是进入组织，为什么会影响后续变化？第 2 篇把系统中的总量记成一个数；本篇把血液和组织分开记账，追踪物质在两处怎样转移。两条收支逐步引出向量与矩阵，随后用两室的和、差解释不同快慢的变化。

当清除不再与当前总量成正比，固定矩阵还能描述变化吗？我们将从一次小扰动建立局部近似，再改变扰动幅度和计算步长，检查近似何时够用。按下表顺序阅读，每节末尾可进入对应练习。

| 小节 | Notebook | 学习重点 |
|---|---|---|
