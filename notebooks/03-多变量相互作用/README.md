# 第 3 篇：多变量相互作用

本目录提供网页正文的动手实验：建立两室收支、分解动态模态，再比较相轨迹与局部近似。完整讲解、推导及习题从[第 3 篇网页目录](http://127.0.0.1:8000/parts/03-多变量相互作用/)进入。

按下表顺序运行，每本均可从全新内核执行。状态列表按室 1、室 2 排列；总量或偏差以 U、时间以 T 计，具体参数单位见各实验。

| 小节 | 实验 Notebook | 实验内容 |
|---|---|---|
| 3.1.1 | [两室交换与矩阵收支](01-从多个室进入线性代数/01-两室交换与矩阵收支.ipynb) | 分别用逐项收支与矩阵乘法推进两室总量，检查内部交换和外部收支。 |
| 3.1.2 | [内积、范数与投影](01-从多个室进入线性代数/02-内积范数与投影.ipynb) | 把两室偏差拆成共同变化与重新分配，核对投影及余量的几何关系。 |
| 3.1.3 | [平衡方程、秩与唯一性](01-从多个室进入线性代数/03-平衡方程秩与唯一性.ipynb) | 比较只有内部交换与带外部收支时的平衡方程，用总量约束或独立收支选出平衡。 |
| 3.2.1 | [状态、输入与观测映射](02-线性状态空间与动态模态/01-状态输入与观测映射.ipynb) | 对同一段两室交换过程选择不同读数，比较内部状态与观测曲线。 |
| 3.2.2 | [特征值、模态与矩阵传播](02-线性状态空间与动态模态/02-特征值模态与矩阵传播.ipynb) | 把两室动态分成共同衰减与差异衰减，再重建室内总量。 |
| 3.2.3 | [复数模态与阻尼旋转](02-线性状态空间与动态模态/03-复数模态与阻尼旋转.ipynb) | 用两个实数偏差观察衰减和旋转，并比较特征向量不足时的时间项。 |

| 3.3.2 | [交换通道与平衡集合](03-耦合、相平面与平衡/02-通道改变与平衡集合.ipynb) | 依次关闭回流和全部通道，比较两室长期分配及平衡集合。 |
| 3.4.1 | [偏导、梯度与雅可比矩阵](04-多变量变化与局部线性化/01-偏导梯度与局部变化.ipynb) | 逐分量检查饱和清除模型的局部导数，并观察有限差分误差随扰动改变。 |
| 3.4.2 | [平衡附近的线性化与误差](04-多变量变化与局部线性化/02-线性化能够走多远.ipynb) | 从相同扰动初值推进原模型与局部模型，再用半步长区分模型差异和数值差异。 |
| 篇末综合 | [二室交换、观测与局部近似](05-篇末综合/01-二室交换与局部近似综合实验.ipynb) | 将平衡总量、浓度观测、内部转移和局部近似放在同一组实验中比较。 |
