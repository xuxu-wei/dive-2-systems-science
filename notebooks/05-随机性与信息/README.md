# 第 5 篇：随机性与信息

同样的细胞、同样的测量规则，为什么每次读数仍会不同？前四篇用状态方程解释变化，本篇从一次标签和一段误差区间开始，用概率描述尚未确定的结果，再通过重复实验看清这种描述如何对应实际频率。

我们先手算释放量的平均和散布，再区分共享偏移、测量误差与逐步进入状态的扰动。看到标记后，判断怎样更新？经过一个周期后，标签怎样切换？最后比较读数减少的不确定性，并检查有限样本与分箱会怎样影响信息估计。各节先说明对象和必要条件，再连接公式、代码与结果。
