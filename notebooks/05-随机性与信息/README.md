# 第 5 篇：随机性与信息

本目录提供网页讲授的独立实验：从重复抽样进入概率，用矩描述噪声，再比较条件更新、随机路径、分布传播和信息估计。完整讲解与练习从[第 5 篇导览](http://127.0.0.1:8000/parts/05-随机性与信息/)进入。

每本可从新内核按顺序运行；先查看模型与单位，再修改参数并比较结果。固定种子可重播同一组结果，独立重复用于查看抽样波动。

| 小节 | 实验 Notebook | 内容 |
|---|---|---|
| 5.1.1 | [样本空间、随机变量与概率分布](01-从重复实验建立概率/01-事件分布与一次实现.ipynb) | 从细胞标签与误差区间进入概率，解释事件、变量、一次结果和密度面积。 |
| 5.1.2 | [独立抽样与重复实验](01-从重复实验建立概率/02-把抽样变成可比较的重复实验.ipynb) | 按相同概率重复抽取细胞，比较每组细胞数、重复次数及两种频率汇总方式。 |
| 5.2.1 | [期望、方差与独立平均](02-期望、方差、协方差与噪声/01-用期望与方差描述随机量.ipynb) | 用两种释放量手算期望和方差，再解释独立平均、样本分母及高斯误差。 |
| 5.2.2 | [联合分布、协方差与共享偏移](02-期望、方差、协方差与噪声/02-联合变化与协方差.ipynb) | 从配对表求边缘与协方差，比较平方关系和共享偏移对独立平均的影响。 |
| 5.2.3 | [过程噪声、测量噪声与个体差异](02-期望、方差、协方差与噪声/03-过程测量与个体差异.ipynb) | 把扰动放进状态与读数方程，推导两种方差，再解释固定个体差异和路径分位带。 |
| 5.3.1 | [条件概率、贝叶斯公式与条件期望](03-条件概率与贝叶斯更新/01-由条件概率推导贝叶斯更新.ipynb) | 从标记的两种来源计算后验，再用联合表手算已知测量方式后的条件平均。 |
| 5.3.2 | [高斯后验、精度与重复测量](03-条件概率与贝叶斯更新/02-固定未知量的高斯更新.ipynb) | 对先验与似然的平方项配方，推导均值、方差和精度更新，比较剩余先验差异。 |
| 5.4.1 | [随机过程、马尔可夫状态与分布传播](04-随机过程与马尔可夫模型/01-状态路径与概率分布的两种推进.ipynb) | 先按静息、活跃顺序算两步概率，再生成一条路径并比较同刻群体频率。 |
| 5.4.2 | [不变分布、周期与长期收敛](04-随机过程与马尔可夫模型/02-不变分布与长期收敛的条件.ipynb) | 用必定交替与两个吸收态区分不变和收敛，从两态偏差递推求长期行为。 |
| 5.4.3 | [随机游走、漂移与扩散](04-随机过程与马尔可夫模型/03-随机游走中的漂移与扩散.ipynb) | 累加左右位移，分别求漂移与位置方差，解释零均值时群体仍会扩散。 |
| 5.5.1 | [离散熵、条件熵与互信息](05-熵、互信息与测量价值/01-熵与互信息的离散定义.ipynb) | 比较复制、独立和翻转读数，从联合表计算熵与互信息，解释平均减少的不确定性。 |
| 5.5.2 | [分箱、有限样本与信息估计](05-熵、互信息与测量价值/02-有限样本分箱与信息偏差.ipynb) | 将配对读数编码成箱号，比较同一样本的嵌套分箱与独立重复中的估计偏差。 |
