# 2.4.3 输入跳变与分段模拟

学完本节，你应能在输入改变的时刻拆分计算步，按每步实际时长更新，并用连续接续的分段解析解检查数值误差。

**先修知识**：[数值稳定性与非负性](/chapters/02-04-数值模拟、误差与迁移/read/2/)；恒定输入解析解、累计流入与网格误差。

## 输入跳变与累计流入 {#input-jump-cumulative-amount}

示踪物质从时刻零到 3 T 以 2 U/T 流入一个池，此后停止流入，继续观察到 5 T。这样的速率在 3 T 突然改变，称为输入的**跳变（jump discontinuity）**：紧靠切换点左边与右边的速率不同。

若计划每步走 0.8 T，时间点会依次是 $0,0.8,1.6,2.4,3.2,\ldots$ T。其中 $2.4\to3.2$ T 跨过了停止输入的时刻：前 0.6 T 还有输入，后 0.2 T 已没有输入。

| 时段 / T | 时长 / T | 流入速率 / (U/T) | 累计流入 / U |
|---|---:|---:|---:|
| $2.4\to3$ | 0.6 | 2 | 1.2 |
| $3\to3.2$ | 0.2 | 0 | 0 |

整步都用旧速率会记入 $0.8\times2=1.6$ U，比实际多 0.4 U；整步都用新速率则会漏掉 1.2 U。让计算在 3 T 停一步，就能给前后两部分分别使用正确速率。

## 分段时刻、时间网格与实际步长 {#aligned-grid-actual-step}

用 $b_j$ 表示输入时段的端点，下标 $j$ 从零开始；$u_j$ 表示 $b_j\le t<b_{j+1}$ 内的恒定流入速率。本例的对应关系是：

| 输入时段序号 $j$ | 起点 $b_j$ / T | 终点 $b_{j+1}$ / T | 速率 $u_j$ / (U/T) |
|---:|---:|---:|---:|
| 0 | 0 | 3 | 2 |
| 1 | 3 | 5 | 0 |

三个端点围出两个时段，所以端点列表为 $[0,3,5]$，速率列表为 $[2,0]$，后者少一项。每个速率都对应一整段，而不是对应一个孤立时刻。

**时间网格（time grid）**是计算所使用的有序时间点。将计划的 0.8 T 记为**名义步长** $h$：在每个输入时段内从左端重新布点，尽量走 $h$，最后不足 $h$ 的部分缩短到该段终点。得到

$$0,\ 0.8,\ 1.6,\ 2.4,\ 3,\ 3.8,\ 4.6,\ 5\quad(\mathrm T).$$

3 T 只保留一次，它既是上一段终点，也是下一段起点。后一段从 3 T 重新安排，所以接下来是 3.8 T。

再用 $t_i$ 表示完整网格的第 $i$ 个点，定义**实际步长**

$$\Delta t_i=t_{i+1}-t_i.$$

$i$ 数计算小步，$j$ 数输入时段。若第 $i$ 步落在第 $j$ 段，欧拉更新为

$$\boxed{A_{i+1}=A_i+\Delta t_i(u_j-kA_i).}$$

从 2.4 到 3 T 使用旧速率 2 U/T，时长为 0.6 T；从 3 到 3.8 T 使用新速率零。最后从 4.6 到 5 T 只有 0.4 T。每一步的收支与非负条件都要用对应的 $\Delta t_i$，例如检查 $k\Delta t_i\le1$。

## 总量连续与变化率跳变 {#state-continuity-rate-jump}

方程现在成为

$$A'=u(t)-kA,$$

消除系数 $k$ 在全过程保持不变。切换时刻改变的是流入速率，池里已经积累的物质仍然存在。输入速率有限，也没有瞬时注入，因此在趋于零的时长内，累计转移量也趋于零，总量在切换点连续。

以 $A_0=0$ U、$k=0.5/\mathrm T$ 为例，输入停止前的解析曲线为

$$A(t)=4\,\mathrm U\left(1-e^{-0.5t/\mathrm T}\right),\qquad0\le t\le3\,\mathrm T.$$

在 3 T 得到约 3.107479 U。停止前一刻的净流率约为 $2-0.5\times3.107479=0.446260$ U/T，停止后一刻变为 $-0.5\times3.107479=-1.553740$ U/T。斜率从正变负，总量却没有跳下来；它从这里开始下降。图上会出现一个转折点。

后半段以 $A(3\,\mathrm T)$ 作为新初值，只有清除，因此

$$A(t)=A(3\,\mathrm T)e^{-k(t-3\,\mathrm T)},\qquad3\,\mathrm T\le t\le5\,\mathrm T.$$

这个指数使用的是停止输入之后经过的时长 $t-3\,\mathrm T$。将 $t=3$ T 代回得到前段末值，因而两段连续接上；到 5 T 时，得到约 1.143178 U。

## 分段解析参考与数值轨迹 {#piecewise-reference-trajectory}

对任意一段恒定输入，在段首 $b_j$ 的精确总量为 $A(b_j)$ 时，后续时刻的解析解为

$$A(t)=A(b_j)e^{-k(t-b_j)}
+\frac{u_j}{k}[1-e^{-k(t-b_j)}],\qquad k>0.$$

每走到下一段，就把本段的**解析末值**带到下一段作为初值。欧拉轨迹则接着自己的数值末值更新。两条轨迹使用相同输入，分别延续自己的计算，才能保留此前已经积累的差异。

继续用 $A_0=0$ U、$k=0.5/\mathrm T$、$h=0.8$ T。欧拉法在切换前的最后一步为

$$A(3\,\mathrm T)\text{ 的欧拉近似}
=3.136+0.6(2-0.5\times3.136)
=3.3952\ \mathrm U.$$

切换后的第一步使用零输入，得到

$$3.3952+0.8(0-0.5\times3.3952)=2.03712\ \mathrm U.$$

两条轨迹在几个对应时刻为：

| 时刻 / T | 欧拉总量 / U | 解析总量 / U |
|---:|---:|---:|
| 0 | 0 | 0 |
| 2.4 | 3.136000 | 2.795223 |
| 3 | 3.395200 | 3.107479 |
| 3.8 | 2.037120 | 2.083006 |
| 5 | 0.977818 | 1.143178 |

## 零清除核算与两类误差 {#zero-clearance-and-error-checks}

若 $k=0$，分段解析式成为 $A(t)=A(b_j)+u_j(t-b_j)$。每段都是直线，欧拉法使用正确时长时恰好得到同样的变化。终值可以直接由累计输入核算：

$$A(t_{\rm end})=A_0+\sum_j u_j(b_{j+1}-b_j).$$

例如从 1 U 出发，前 3 T 以 2 U/T 输入、后 2 T 停止输入，末量为 $1+2\times3+0\times2=7$ U。无论名义步长怎样划分，完整计入这两段后都应得到同一总量。

有清除时，可以先检查程序是否按指定的欧拉更新计算，再比较它与分段解析解的差。前者查的是实现，后者查的是时间近似。如果程序与欧拉参考值只差 $10^{-10}$ U，而与连续解差 0.1 U，这两个结果可以同时成立；把比较程序的容差放宽，并不会让数值曲线更接近连续解。减小步长再比较，才能观察近似误差怎样改变。

本节固定步长方法遇到已知跳变时，先在该处结束当前步，再按新的输入继续。使用其他求解器时，也应显式提供或处理已知不连续点，并检查附近误差；是否需要手工分段或重新启动，由所用算法和实现决定。求解器输出了切换时刻的一个值，与其内部计算步恰好在此结束，是两件不同的事。

下一步可以把单次停止输入扩展为多段方案：总输入相同，安排在较早或较晚的时段，终点会留下相同的量吗？分段解已经给出了回答这个问题所需的计算方法。
