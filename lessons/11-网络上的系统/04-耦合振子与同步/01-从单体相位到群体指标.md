# 11.4.1 相位向量、序参量与网络耦合

学完本节，你应能用单位圆向量计算相位集中程度，解释反相分组的全局抵消，并从相位差理解节点之间的耦合。

**先修知识**：第 4 篇的振荡与相位，11.1 的邻接矩阵，以及复数的单位圆表示。

## 周期位置与单位相位向量 {#cycle-position-and-unit-phase-vector}

四个细胞节律的相位为 $(0,0,\pi,\pi)$ rad。前两个处在相同周期位置，后两个也一致，但两组相差半个周期。怎样用一个量描述它们整体上有多一致？

沿用第 4 篇，相位 $\theta$ 记录一个周期中的位置，转过一周为 $2\pi$ rad。三角函数采用弧度数值，将相位映到单位圆：

$$v(\theta)=(\cos\theta,\sin\theta).$$

$\theta=0$ 时向量朝右，$\pi/2$ 时朝上，$\pi$ 时朝左。$\theta$ 与 $\theta+2\pi$ 虽然记录的累计圈数不同，在单位圆上却表示同一位置。

这些单位向量也可写成复数

$$e^{\mathrm i\theta}=\cos\theta+\mathrm i\sin\theta,\qquad \mathrm i^2=-1.$$

实部、虚部分别对应横纵坐标，复数的模就是向量长度。直接平均角度会受所选圈数影响，例如 0 与 $2\pi$ 同相，角度算术平均却为 $\pi$；平均单位向量能保留周期位置的关系。

## 相位序参量与全局抵消 {#phase-order-parameter-and-global-cancellation}

对 $n$ 个振子，定义平均相位向量

$$z=\frac1n\sum_{j=0}^{n-1}e^{\mathrm i\theta_j}
=\frac1n\sum_j\cos\theta_j+\mathrm i\frac1n\sum_j\sin\theta_j.$$

它的长度

$$\boxed{R=|z|}$$

称为**相位序参量（phase order parameter）**。$j$ 遍历振子，每个单位向量长为 1，因此平均后的长度满足 $0\le R\le1$。全部向量同向时 $R=1$；方向越分散，向量间的抵消可以使它变小。$R$ 是无量纲数。

先手算两个相位 $0,\pi/2$：平均向量为 $(1/2,1/2)$，所以 $R=\sqrt{1/2}\approx0.7071$。全部相位为 0 时，平均仍为 $(1,0)$，得到 $R=1$。

<!-- practice: p11-phase-order-parameter -->

开头的四个相位则给出

$$\frac14\left[(1,0)+(1,0)+(-1,0)+(-1,0)\right]=(0,0),$$

所以全局 $R=0$。分别计算前两个或后两个时，每组的序参量都是 1。全局向量抵消与组内同相能够同时发生，$R$ 要结合它平均了哪些振子来解释。

## 共同相位平移与旋转不变性 {#common-phase-shift-and-rotation-invariance}

如果每个相位共同增加 $\phi$，平均向量变为

$$z^+=\frac1n\sum_je^{\mathrm i(\theta_j+\phi)}
=e^{\mathrm i\phi}z.$$

乘子 $e^{\mathrm i\phi}$ 的模为 1，只将所有箭头一起旋转，故 $R^+=R$。因此指标与哪一个方向被选作零相位无关，描述的是各相位之间的集中程度。

例如一组相位的 $R=0.6$，共同增加半圈或四分之一圈之后，长度仍为 0.6。平均方向改变，向量之间的夹角保持原样。

## 固有角频率与正弦耦合 {#natural-frequencies-and-sinusoidal-coupling}

现在让相位随时间变化。未耦合振子的相位以固有角频率 $\omega_i$ 前进，即 $\dot\theta_i=\omega_i$。相位单位为 rad，角频率为 rad/T。

把邻接矩阵记为 $A$、节点度记为 $d_i=\sum_jA_{ij}$，采用按度归一化的网络相位模型：

$$\boxed{\dot\theta_i=\omega_i+
\frac K{\max(1,d_i)}\sum_jA_{ij}\sin(\theta_j-\theta_i).}$$

$K\ge0$ 的单位为 rad/T。正弦项根据相邻振子的相位差改变当前速度：当邻居领先的角度在 0 与 $\pi$ 之间时，正弦为正，推动本节点加快；邻居落后同样角度时则让它减慢。

对非孤立节点，除以 $d_i$ 让邻居贡献以平均值进入。孤立节点没有邻居，求和为零，便只按自身角频率前进；分母写成 $\max(1,d_i)$ 同时保留这个规则。

模型保存的是各振子的相位。一步 Euler 更新从同一份旧相位计算所有正弦差，再同时写出下一行相位；这样每条边两端计算的都是同一时刻的关系。
