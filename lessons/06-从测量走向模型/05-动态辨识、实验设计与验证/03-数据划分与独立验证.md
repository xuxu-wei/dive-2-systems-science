# 6.5.3 数据划分、缺测与预测验证

学完本节，你应能按未来使用任务划分记录，只用训练信息计算预处理参数，保留缺测的时钟，并用未参与选择的数据评价预测。

**先修知识**：本章的回归与预测，均值、标准差和最小二乘。

## 预测任务与数据划分 {#prediction-task-and-data-partitions}

假设我们想用一个个体已经收到的记录，预测同一个体将来的读数。若随机打散整段时间序列，后期数据就可能参与早期模型，得到的分数回答不了原来的问题。数据应怎样划分，先由未来准备怎么使用模型决定。

**训练数据**用于估计参数和预处理；**验证数据**用于比较预定候选、选择模型；**最终评估数据**在选择完成以后使用，评价这套已确定做法的预测表现。本节按目标时刻分为三段：

| 目标时刻 $t$ / T | 用途 |
|---|---|
| $t<50$ | 训练 |
| $50\le t<75$ | 比较候选、选择输入延迟 |
| $t\ge75$ | 锁定候选后的最终评分 |

这些边界按目标时刻划分，回归行仍可使用预测时已经到达的历史。例如预测第50时刻时，第49时刻的实际读数已经可用。

<!-- practice: p06-time-partition -->

若问题改为预测一个新个体，应将同一个体的全部记录放在同一个集合。否则模型可能在训练时已见过该个体的固定特征。时间划分检查同一个体的未来任务，个体划分检查新个体任务；同时关心两者时，就同时保留个体与未来时段。

例如个体标签依次为甲、乙、甲、丙、乙，训练个体选甲、验证个体选乙，则原索引分别为训练 $[0,2]$、验证 $[1,4]$、最终 $[3]$。同一个体的重复出现不改变所属集合。

## 训练标准化与参数还原 {#training-standardization-and-coefficient-recovery}

不同特征可能有不同量级。标准化先减去训练平均，再除以训练尺度，让拟合使用可比较的数值尺度。对某一列训练特征 $x$，定义

$$\mu_{\rm tr}=\frac1{N_{\rm tr}}\sum_{i\in{\rm tr}}x_i,\qquad
s_{\rm tr}=\sqrt{\frac1{N_{\rm tr}}\sum_{i\in{\rm tr}}(x_i-\mu_{\rm tr})^2},$$

再对各段使用同一个变换 $z=(x-\mu_{\rm tr})/s_{\rm tr}$。$s_{\rm tr}$ 与特征同单位，故 $z$ 无单位。恒定训练特征的数值除数约定为1，相当于在该特征所用单位下取一个单位尺度。

例如训练值为1、3 U，平均为2 U、尺度为1 U，标准化后为 $-1,1$。后来收到5 U，沿用训练变换得到3。如果把5 U提前并入平均和尺度，训练表示本身就会依赖未来数据。

<!-- practice: p06-train-only-transform -->

设标准化空间中的拟合为 $\hat y=c+\sum_j\beta_jz_j$，其中输出仍以U计。代入 $z_j=(x_j-\mu_j)/s_j$：

$$\hat y=\left(c-\sum_j\frac{\beta_j\mu_j}{s_j}\right)
+\sum_j\frac{\beta_j}{s_j}x_j.$$

因此原坐标中的斜率是 $\beta_j/s_j$，截距是 $c-\sum_j\beta_j\mu_j/s_j$。标准化参数与回归系数应一起保存，后续读数才能使用相同模型。

## 缺测时钟与有效回归行 {#missing-observations-and-clock}

原时刻为0、1、2、3、4、5 T，其中1和4 T没有读数。保留的原索引为 $[0,2,3,5]$，相邻有效读数的时间差为2、1、2 T。删空以后把它们当作等间隔序列，会改变模型中的“一拍”。

用原数组位置表示时刻，在缺测位置保留空值。若预测 $y_i$ 需要 $y_{i-1}$，那么目标和上一拍都存在时才形成一行。对上述缺测模式：

| 目标时刻 | 目标是否存在 | 上一拍是否存在 | 能否形成一步回归行 |
|---:|---|---|---|
| 1 | 否 | 是 | 否 |
| 2 | 是 | 否 | 否 |
| 3 | 是 | 是 | 是 |
| 4 | 否 | 是 | 否 |
| 5 | 是 | 否 | 否 |

因此只有第3时刻能用这段记录构造相邻一步行。输入还需按候选延迟取对应的原位置。比较 $u_{i-1}$ 和 $u_{i-2}$ 两个候选时，让它们使用共同有效的目标，才能使误差对应相同读数。

<!-- practice: p06-missing-lags -->

跳过不完整回归行保留了时序关系。若缺测还依赖未观测状态，例如偏差很大时仪器更容易失读，剩余样本便可能偏向某些状态；这是需要进一步研究的采样机制。

## 模型选择与最终评分 {#model-selection-and-final-evaluation}

对每个预定延迟，先用训练行拟合，再在相同验证目标上比较**均方根误差（root mean square error，RMSE）**：

$$\operatorname{RMSE}=\sqrt{\frac1N\sum_i(y_i-\hat y_i)^2}.$$

它先把各目标误差平方求平均，再开方，单位与读数相同。验证误差较小者被选中，完全并列时取较小延迟。此后固定候选、预处理和系数，才计算最终段误差。

如果根据最终结果修改输入结构或调参，原来的最终段就参与了模型选择；更新后的模型应交给新的预留观测评价。这与第1篇根据数据更新模型以后，再寻找独立验证的顺序相同。

<!-- practice: p06-held-out-purpose -->

本节评价一步预测：每个时刻可以使用上一拍实际读数。冻结的是拟合模型，不是后续读数。如果使用任务只有段起点，之后收不到实际状态，就应另按自由运行计算。

## 输入范围变化与残差 {#input-range-change-and-residuals}

下面的数据来自含输入饱和的关系：

$$y_{n+1}=0.82y_n+(0.25\,\mathrm U)
\tanh\!\left(\frac{u_n}{1\,\mathrm V}\right).$$

输入先除以1 V成为无单位数，再进入双曲正切函数 $\tanh z=(e^z-e^{-z})/(e^z+e^{-z})$。它在零附近近似为 $z$，大正、负输入时分别趋近1、$-1$，所以输出作用逐渐饱和。候选模型均为线性回归，分别让当前区间输入或前一区间输入起作用。

训练与验证使用 $\pm0.5$ V，最终段扩大到 $\pm1.8$ V。先在训练与验证段选好延迟并固定模型，再查看它在新幅度下的结果。

<!-- experiment: 50d5d181 figure -->

左图保留缺测的原时刻；测试预测仅画在共同有效目标上。右图画对应残差 $y_i-\hat y_i$，空心圈表示所用输入超出训练范围的目标。

在 $\pm0.5$ V这两个幅度下，输入饱和项可以由一个线性增益对应。扩大到 $\pm1.8$ V以后，真实输入作用逐渐饱和，线性模型却继续按幅度放大，残差呈现系统变化。这个对照把训练范围之外的预测与此前的良好拟合联系起来。

残差相关也按原时钟计算：只比较原索引相差1的有效残差对。缺口两侧的两个有效值相邻地存在于列表中，不代表它们相隔一拍。将误差与时刻、输入范围一起查看，可以为下一次候选设计提供具体线索。

下一章保留这种先后顺序，让新的读数逐条更新参数。更新可以更及时，但当前读数仍应在它的评分预测之后才被使用。
