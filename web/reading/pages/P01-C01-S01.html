1.1.1 边界、状态与观测

学完本节，你应能根据问题选择观察范围，分清要描述的量与仪器读数，并计算已知偏移下的被测温度。

先修知识：基础 Python 列表、循环与函数；中学代数的移项。

读数下降，什么在下降

跑步结束后，我们在同一个体表位置连续测了三次温度，读数一次比一次低。这是一条容易描述的记录：仪器显示的数值下降了。可是，如果把它写成“身体内部每一处都在降温”，我们已经在记录之外多走了一步。

先看这一步多出了什么。仪器测的是一个位置，我们关心的却可能是另一处温度，或者整个身体的恢复过程。体表与内部的温度是不同的量；即使仪器完全准确，一处的变化也不能直接代替另一处的变化。导论已经提醒我们关注组成与联系，现在需要把“我们究竟在研究什么”说得更具体。

为此，我们先决定哪些对象属于这次研究，哪些对象作为外界处理。这条划分称为系统边界（system boundary）。它可以是实际容器的壁，也可以是一条根据研究问题画出的界线。例如，追踪血液中的某种物质时，从血液进入组织属于离开系统；如果追踪血液与组织合起来的总量，同一笔移动就发生在系统内部。物质没有因为我们改了边界而改变去向，改变的是我们要回答的问题。

温度问题也一样。若要描述某个固定位置的温度，我们可以先把这个位置作为研究对象。若要解释体表与内部为何变化不同，就需要同时保留两处温度及其联系。扩大边界能容纳更多联系，也需要更多信息；合适的边界应当帮助回答眼前的问题。

模型需要记住哪些量

确定对象以后，我们还要决定如何描述它。想象一张用于继续计算的记录卡：卡上需要保留哪些数值，才能按所选规则算出下一时刻的情况？**状态（state）**是在给定模型规则与后续输入时，足以确定后续演化的当前变量。记录卡的比喻告诉我们：只保留与继续计算有关的信息。在一个十分简化的局部温度模型中，我们可能只在卡上写下当前温度 $x$；如果研究两处之间的传热，一张只写一个温度的卡就可能不够。

这里的**模型（model）**是为回答问题而保留必要关系的一种表示。我们并不把身体中的每一个量都列为状态，而是先选择要保留的量，再说明省略了什么。对于给定规则的确定性模型，当前状态和今后的外界作用共同决定后续的计算结果。

外界作用称为输入（input）。例如，将环境温度记为 $u$，可以让它随时间改变，并考察局部温度如何响应。规则中用来表征关系、在一次计算中按给定值使用的量，称为参数（parameter）。假如我们用传热系数 $k$ 表示某项传热作用的强弱，$k$ 就是这条规则的参数。改变环境温度与改变传热系数，会改变模型的不同部分。

这些量还不能与仪器读数混在一起。实际记录到的读数是观测（observation），记为 $y$。如果状态 $x$ 指内部温度、观测 $y$ 来自体表，那么由 $y$ 推断 $x$，还需要建立体表、内部与环境之间的关系。接下来先处理一个更小的问题：仪器与它正在测量的那个位置之间，存在已知的读数偏移。

先校正仪器的偏移

以下三个读数 $37.4$、$37.1$、$36.9\ ^\circ\mathrm{C}$ 是人工构造的教学数值。现在用 $x$ 表示固定被测位置的温度，$y$ 表示仪器读数。假设校准已告诉我们，这台仪器的每次读数都比被测温度高 $0.3\ ^\circ\mathrm{C}$，并且本例暂不包含随机测量误差。

“读数比被测温度多一个固定量”可以写成

$$y=x+b,$$

其中 $b$ 是偏移参数，本次取 $0.3\ ^\circ\mathrm{C}$。要找回 $x$，就在等号两边减去同一个 $b$：

$$y-b=x+b-b=x,\qquad x=y-b.$$

第一条记录由此得到 $37.4-0.3=37.1\ ^\circ\mathrm{C}$。第二条得到 $37.1-0.3=36.8\ ^\circ\mathrm{C}$，第三条得到 $36.9-0.3=36.6\ ^\circ\mathrm{C}$。这三次减法校正了仪器对同一个被测位置的偏移；要由该位置进一步推断另一处温度，还需要另一项关系。

为了对三次记录依次做同样的减法，我们把读数按观测先后排成 Python 列表 readings = [37.4, 37.1, 36.9]。方括号里第一个数对应第一次读数，第二个数对应第二次，第三个数对应第三次，单位都是 °C。已知偏移单独记为 offset = 0.3，让它作用于每一次读数。计算得到的列表也保持同样顺序，使每个推断值都能与原读数配对。

下面把手算写成列表运算。value - offset 处理一次读数，for value in readings 让同一个减法依次作用于三次记录。

import matplotlib.pyplot as plt
from IPython.display import Markdown, display
from systems_science import plot_style, show_table

plot_style()
plt.rcParams.update({'font.sans-serif': ['Microsoft YaHei', 'SimHei', 'DejaVu Sans'],
                     'axes.unicode_minus': False})
readings = [37.4, 37.1, 36.9]  # 人工温度读数，°C
offset = 0.3                   # 假定由独立校准得到的偏移，°C
estimates = [value - offset for value in readings]

display(Markdown(show_table(['观测顺序', '仪器读数 y / °C', '被测温度推断值 x / °C'],
                           zip(range(1, 4), readings, estimates))))
观测顺序 仪器读数 y / °C 被测温度推断值 x / °C
1 37.4 37.1
2 37.1 36.8
3 36.9 36.6

三个推断值都比读数低 $0.3\ ^\circ\mathrm{C}$，整组数值向下移了同样的距离。那么，第一条到第二条记录的下降幅度是否也改变了？直接算一算：读数之差为 $37.1-37.4=-0.3\ ^\circ\mathrm{C}$；推断值之差为 $36.8-37.1=-0.3\ ^\circ\mathrm{C}$。为了把这次比较写成式子，用 $y_1$、$y_2$ 表示第一次、第二次读数，用 $x_1$、$x_2$ 表示对应的被测温度。下标在这里表示观测次序。Python 列表的位置从 0 开始编号，所以第一次、第二次读数在代码中分别是 readings[0]、readings[1]。两个差相同，因为固定的偏移在相减时消去了：

$$x_2-x_1=(y_2-b)-(y_1-b)=y_2-y_1.$$

下图把同一结果画出来。plot(横坐标, 纵坐标) 将每条记录画成一个点，label 给这组点命名。这里没有提供实际测量时刻，所以横轴只表示第几次观测，不能据此计算每分钟的变化。

def infer_measured_temperature(readings, offset):
    return [value - offset for value in readings]

order = [1, 2, 3]
fig, ax = plt.subplots()
ax.plot(order, readings, 'o-', label='仪器读数 y')
ax.plot(order, infer_measured_temperature(readings, 0.3), 's--',
        label='被测温度 x：假定 b = 0.3 °C')
ax.set(xlabel='观测顺序', ylabel='温度 / °C', xticks=order)
ax.legend()
plt.show()

同一组读数，能有两个解释吗

刚才我们能够算出三个 $x$，关键是已经知道 $b$。现在保留原来的读数，拿走独立校准的信息。仅凭 $y=37.4\ ^\circ\mathrm{C}$，是否能判断仪器偏移了多少？

试着给出两组数。若 $b=0.3$，则 $x=37.1$，加回去得到 $37.1+0.3=37.4$。若 $b=0.6$，则 $x=36.8$，加回去同样得到 $36.8+0.6=37.4$。两组都满足测量关系，也都符合这条读数。

这项歧义并不会因为我们记录了三次就自动消失。第一种解释给出 $[37.1,36.8,36.6]$；第二种给出 $[36.8,36.5,36.3]$。每一组加回各自的固定偏移，都能还原 $[37.4,37.1,36.9]$。下面只改变假定的偏移量，检验这一点。

for assumed_offset in [0.3, 0.6]:
    inferred = infer_measured_temperature(readings, assumed_offset)
    rebuilt = [x + assumed_offset for x in inferred]
    assert all(abs(a - b) < 1e-12 for a, b in zip(readings, rebuilt))
    print(f'b = {assumed_offset:.1f} °C 时，推断值为 {[round(x, 2) for x in inferred]}')

assert abs((readings[1] - readings[0]) - (estimates[1] - estimates[0])) < 1e-12

b = 0.3 °C 时，推断值为 [37.1, 36.8, 36.6]
b = 0.6 °C 时，推断值为 [36.8, 36.5, 36.3]

两种偏移假设都通过了“加回去能否重建读数”的检查。因此，重建成功只能说明我们按假定关系完成了计算，不能替我们选出正确的偏移量。要确定绝对温度，还需要独立校准等额外信息。在这个固定偏移模型内，读数间的差仍能确定；如果偏移本身随时间改变，这个结论也需要重新检查。

现在可以回看本节的几个角色：

角色 在固定位置测温例子中表示什么
研究对象与范围 固定的被测位置；将周围环境作为外界处理
状态 $x$ 简化模型保留的该位置温度
观测 $y$ 仪器实际记录的读数
输入 $u$ 例如环境温度；用于描述外界对温度变化的作用
参数 $b$ 测量关系中的固定偏移；本节据此校正读数

表中的角色取决于我们正在建立的模型。同样使用 °C，并不意味着两个量相同；有了仪器校准，也不等于已经建立体表到内部的关系。这两层区别，正是开篇从“读数下降”走向“什么在下降”时需要补上的内容。

把大问题写成可以检查的小问题

确定对象与观测以后，我们便能改写一个含糊的问题。比如“细胞为什么总能适应”包含许多还没有指定的过程。若手头的实验是每小时拍摄同一个培养孔，共观察 4 小时，可以先问：“按同一计数规则，0—4 小时的可见细胞数是否增加？”这句话指出了对象、观察范围、可测量结果，也容许照片给出“没有增加”的答案。

计数增加仍不够说明增加由哪种过程造成。要区分分裂、迁入或其他变化，还需记录对应过程。我们会在后面的收支（mass balance）问题中继续追问这一点。眼下还缺少一项最基本的信息：记录对应哪些时刻，数字采用什么单位？下一节从这里开始。
