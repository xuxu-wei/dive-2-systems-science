5.4.3 随机游走、漂移与扩散

学完本节，你应能从一步位移推导平均位置与方差，区分位置散布和均值波动，并解释同一路径中不同时刻的位置为何相关。

先修知识：5.2 的期望、方差和协方差；5.4.1 的随机过程、路径与同刻群体分布。

独立位移与位置路径

许多个体都从位置 0 出发，每周期向左或向右移动相同距离。左右同样常见时，群体平均位置可能始终在原点附近，单个个体却不断离开原点、返回、再离开。平均不动与个体散开可以同时发生。

规定每一步以概率 $p$ 向右走 $d$，以概率 $1-p$ 向左走 $d$，$d>0$；各步方向相互独立，位置没有边界。这定义了一种随机游走（random walk）。记第 $i$ 步位移为 $Z_i$，则

$$P(Z_i=d)=p,\qquad P(Z_i=-d)=1-p,\qquad X_n=\sum_{i=1}^nZ_i,\quad X_0=0.$$

$Z_i$ 是这一步增加的位置，$X_n$ 是前 $n$ 步累积到达的位置。取 $d=1\,\mathrm L$，指定前五步方向为 $[1,-1,1,1,-1]$，累加为

已完成步数 $n$ 本步位移 / L 位置 $X_n$ / L
0 — 0
1 1 1
2 −1 0
3 1 1
4 1 2
5 −1 1

位置序列多包含一个起点，因此比位移序列长一项。给定这些具体方向后得到一条路径；求第 $n$ 步的位置分布时，则要考虑所有可能的方向组合。

一步期望与多步漂移

一步只有两种可能位移，按概率平均得到

$$E[Z_i]=pd+(1-p)(-d)=d(2p-1).$$

把每步期望相加，

$$\boxed{E[X_n]=nd(2p-1).}$$

平均位置每步改变的量 $d(2p-1)$ 称为每步漂移，单位为 L/步。$p=1/2$ 时漂移为零；$p>1/2$ 时向右；$p<1/2$ 时向左。计算期望和只用到期望的可加性；后面求方差时还会用到增量独立。

例如 $p=0.65,d=1\,\mathrm L$，一步平均位移为 $0.3\,\mathrm L$，第 10 步平均位置为 $3\,\mathrm L$。它是许多可能路径的概率平均，不要求每条路径恰好到达 3 L。

一步方差与位置扩散

左右两种位移的平方都为 $d^2$，所以

$$E[Z_i^2]=pd^2+(1-p)d^2=d^2.$$

使用 $\operatorname{Var}(Z_i)=E[Z_i^2]-(E[Z_i])^2$，

$$\begin{aligned} \operatorname{Var}(Z_i) &=d^2-d^2(2p-1)^2\\ &=d^2[1-(4p^2-4p+1)]\\ &=4d^2p(1-p). \end{aligned}$$

各步增量相互独立，交叉协方差为零，因此它们的方差相加：

$$\boxed{\operatorname{Var}(X_n)=4nd^2p(1-p).}$$

方差单位为 $\mathrm{L^2}$，描述所有个体在同一时刻的平均位置周围散布多大。用两种方向概率比较前几步：

步数 $p=0.5$ 的均值 / L $p=0.5$ 的方差 / $\mathrm{L^2}$ $p=0.65$ 的均值 / L $p=0.65$ 的方差 / $\mathrm{L^2}$
0 0 0 0 0
1 0 1 0.3 0.91
2 0 2 0.6 1.82
3 0 3 0.9 2.73

这里 $d=1\,\mathrm L$。零漂移的群体散开，向右漂移的群体也在移动的平均位置周围散开；当 $p=0$ 或 1 时，所有路径都朝同一方向走，方差才为零。

均方根位移与两步枚举

对称游走中，$E[X_n]=0$，故 $E[X_n^2]=\operatorname{Var}(X_n)=nd^2$。于是均方根位移为

$$\sqrt{E[X_n^2]}=d\sqrt n.$$

它给出个体离开起点的一个典型长度尺度。两步对称游走可以完全枚举，四种等概率的方向组合是

两步方向 终点
右、右 $2d$
右、左 $0$
左、右 $0$
左、左 $-2d$

平均终点为零，但平方后平均得到

$$E[X_2^2]=\frac{(2d)^2+0+0+(-2d)^2}{4}=2d^2.$$

所以均方根位移为 $d\sqrt2$。平方先把正负位移都计入，再求平均，才能看见左右抵消所隐藏的散布。

有漂移时，应保留均值项：$E[X_n^2]=\operatorname{Var}(X_n)+(E[X_n])^2$。此时均方根位移还包含整个群体中心移动的距离，与仅描述中心周围宽度的标准差不同。

同一路径的位置相关性

独立的是每一步新增的位移。相邻两个位置共享已经走过的路，通常并不独立。对 $m\leq n$，把后一个位置拆成

$$X_n=X_m+\sum_{i=m+1}^nZ_i.$$

后续增量与 $X_m$ 独立，因此

$$\begin{aligned} \operatorname{Cov}(X_m,X_n) &=\operatorname{Cov}(X_m,X_m) +\operatorname{Cov}\!\left(X_m,\sum_{i=m+1}^nZ_i\right)\\ &=\operatorname{Var}(X_m)+0. \end{aligned}$$

例如对称单位步长游走中，$\operatorname{Cov}(X_2,X_3)=2\,\mathrm{L^2}$，因为两个位置都包含前两步的位移。要估计某个时刻的群体分布，可以模拟许多独立路径，取它们在同一时刻的位置；同一路径的一串位置包含这种时间相关性。

漂移、散布与有限路径实验

下面对 $p=0.5$、$0.65$ 各生成 200 条独立路径，每条走 60 步，步长均为 1 L。左图比较群体平均位置及理论均值，阴影为每个时刻各条路径位置的经验 5%—95% 分位范围；右图比较样本位置方差与理论方差。

对称游走的经验均值围绕零波动，路径分位范围却越来越宽。偏向右侧的游走同时表现出中心右移和宽度增大。右图两条理论线分别为 $n\,\mathrm{L^2}$ 与 $0.91n\,\mathrm{L^2}$。

分位带描述同一时刻不同个体的位置散布。经验均值本身的波动则更小：若路径数为 $B$，其方差为 $\operatorname{Var}(X_n)/B$。增加 $B$ 会提高平均位置估计的精度，个体位置的理论方差仍由步数和单步规则决定。

扩散系数与空间边界

若每步用时 $\Delta t$，则 $n$ 步对应物理时间 $t=n\Delta t$。对称游走的位置方差可以写成

$$\operatorname{Var}(X_n)=nd^2=\frac{d^2}{\Delta t}t=2Dt, \qquad \boxed{D=\frac{d^2}{2\Delta t}.}$$

$D$ 叫作扩散系数（diffusion coefficient），单位为 $\mathrm{L^2/T}$。例如 $d=1\,\mathrm L$、$\Delta t=0.5\,\mathrm T$，则 $D=1\,\mathrm{L^2/T}$。这个系数将一步距离、一步耗时与长期位置散布联系起来。进一步取连续扩散近似时，要同时缩小 $d$ 和 $\Delta t$ 并保持 $d^2/(2\Delta t)$，让越来越细的随机步保留相同的方差增长尺度。

如果把位置限制在有限区间并在端点反射，移动规则便发生变化。位置始终有界，所以方差也有上界，不能沿用无边界模型的 $nd^2$ 无限增长。此时可以像前两节那样，先写出含端点规则的转移矩阵，再研究其分布与长期行为。
