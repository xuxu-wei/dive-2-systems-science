4.4.3 有限时间增长率与算术精度

学完本节，你应能从逐代乘子推导平均对数增长率，处理零导数与特殊轨道，并比较同一数学初值在不同算术精度下的记录。

先修知识：邻近轨迹与预测期限；链式法则、自然对数和 Python 数值类型。

乘子积与平均对数增长率

两条轨迹的最后距离同时受各代变化和距离饱和影响。要描述一段轨迹对微小扰动的作用，可以沿着这条轨迹逐代乘局部导数。

对于 $x_{n+1}=F(x_n)$，连续应用一阶近似：

$$\begin{aligned} \delta_1&\approx F'(x_0)\delta_0,\\ \delta_2&\approx F'(x_1)F'(x_0)\delta_0,\\ \delta_N&\approx\delta_0\prod_{n=0}^{N-1}F'(x_n). \end{aligned}$$

取绝对值，所乘的都是长度倍率。再取自然对数，乘积变成求和：

$$\log\left|\prod_{n=0}^{N-1}F'(x_n)\right| =\sum_{n=0}^{N-1}\log|F'(x_n)|.$$

除以更新次数，定义这段轨迹的有限时间 Lyapunov 指数（finite-time Lyapunov exponent）：

$$\boxed{\lambda_N=\frac1N\sum_{n=0}^{N-1}\log|F'(x_n)|.}$$

本章也称它为有限时间增长率，按每代计算。正值说明这个窗口的乘子绝对值之积大于 1，负值说明小于 1。平均为正不要求每一步都放大；其中几步的收缩可以被其他步的伸长超过。

先用不动点手算。$r=2.5$ 时，$x_*=0.6$，每一步乘子都为 $-0.5$，所以

$$\lambda_N=\frac{N\log0.5}{N}=\log0.5\approx-0.693147.$$

偏差逐代换边并缩为一半，与负的平均增长率一致。若在 $r=3.2$ 的二周期上记录完整两代，平均值为 $\tfrac12\log|F'(p)F'(q)|=\tfrac12\log0.16\approx-0.916291$。

暂态、记录窗口与增长率

实验先推进 burn 次，去掉这段暂态，再记录接下来 steps 个当前状态处的导数。每一项都先用当前 $x_n$ 计算 $\log|r(1-2x_n)|$，再更新状态；因此，若记录 $N$ 项，使用的是窗口中前 $N$ 个状态处的乘子。

延长窗口，可以查看平均值是否逐渐稳定；改变暂态长度，可以比较早期运动的影响；换初值，则检查另一条轨迹。只有当相应的无限时间极限存在时，才把这个极限称为该轨迹的渐近 Lyapunov 指数。有限窗口的计算首先描述它实际经过的这段运动。

零导数与特殊轨道

若窗口中有一步 $F'(x_n)=0$，一阶扰动乘积就为零，按极限解释的对数项为 $-\infty$。当前计算题用 None 表示这一情况，以便将它与普通有限平均值区分。

零导数意味着一阶变化消失，有限大小的扰动还可能通过高阶项传播。例如 $x=1/2$ 时，直接展开得到

$$F\left(\frac12+\delta\right)-F\left(\frac12\right)=-r\delta^2.$$

小偏差在这一更新后变成平方量级，并非所有不同初值都得到同一个值。

在 $r=4$ 时，精确初值 $x_0=1/2$ 给出

$$\frac12\longrightarrow1\longrightarrow0\longrightarrow0\longrightarrow\cdots.$$

这是一条最终停住的特殊轨道。如果窗口包含第一步，就会遇到零导数；若从已经到达的 $0$ 开始记录，导数却始终是 4，平均增长率为 $\log4>0$。零点本身保持不动，附近的小扰动则会被放大。这说明轨道的运动方式与它对扰动的作用是两个需要结合观察的方面。

二进制浮点与十进制高精度对照

现在固定数学参数 $r=3.9$、初值 $x_0=0.2$，比较两种算术。Python float 用有限位二进制表示数值，Decimal 可以指定十进制有效位数。两者从同一组十进制定义出发，仍会因初值表示、参数表示和后续舍入产生微小差别。

高精度计算要从字符串 '3.9' 与 '0.2' 建立 Decimal，并在它自己的精度中完成全部更新。先转成 float 再扩充位数，会把原先的二进制近似带进高精度计算。

这里代码本身就是要比较的操作：

from decimal import Decimal, localcontext

with localcontext() as context:
    context.prec = 50
    r = Decimal('3.9')
    x = Decimal('0.2')
    for _ in range(80):
        x = (r * x) * (1 - x)

保持更新顺序为先算 $rx$、再乘 $1-x$，可以把比较集中在数值表示与精度上。图中高精度轨迹只在绘图前转换为普通浮点数，迭代仍用 50 位十进制运算。

左图是同一十进制初值定义下的两条算术轨迹，右图是同一代两种结果的绝对差。早期它们贴合，后期微小舍入差被逐代放大，形成可见分离。右图对数轴仅显示正差值；图上空缺的零差点表示两种绘图数值在该处相同。

较高精度提供舍入更小的数值对照，可以帮助检查分离从何时开始。实际预测还受初始测量误差和模型关系影响，提高算术精度主要改变计算这一环节。

有界运动与局部敏感性

将不动点、二周期和更不规则的轨迹放在一起，可以看到长期运动由几方面共同描述：状态是否有界、是否重复、对小扰动是收缩还是伸长。$r=3.9$ 的记录中，状态留在 $[0,1]$，邻近轨迹却能逐渐分开；有界限制整体范围，局部伸长影响逐点预测。

数学上对混沌的严格定义通常还要求在指定不变集上讨论长期动力学性质。本章计算的是给定初值、窗口与精度下的轨迹及扰动增长；这些量为分析复杂运动提供可逐项检查的线索。接下来改从整个状态区域出发，寻找能沿所有轨迹下降的函数，用另一种方式分析稳定性。
