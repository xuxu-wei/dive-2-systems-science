3.2.3 复数模态与阻尼旋转

学完本节，你应能用单位圆解释旋转，用复数合记两个实数偏差，读出复特征值的衰减与旋转含义，并求解一个特征向量不足的二维系统。

先修知识：上一节的特征值、模态与矩阵指数；勾股定理、圆周长；第 2 篇的导数、乘积求导和积分。

偏差坐标与平面旋转

前面两室交换的量逐渐靠近平衡。另一些调节过程会出现交替起伏：某个量高于参考值后又低于它，另一个量的峰值则稍后出现。把同一时刻的两个偏差放在平面上，可以把两条起伏曲线联系成一个旋转过程。

本节构造两个偏差 $x_1,x_2$，均以 U 表示相对固定参考量的差。状态顺序为 $x=(x_1,x_2)^{\mathsf T}$。例如参考量为 5 U，偏差 $x_1=-0.2$ U 对应实际量 4.8 U。偏差的正负表示相对参考的位置；到原点的距离 $\sqrt{x_1^2+x_2^2}$ 则表示两个偏差合起来有多大。

考虑从 $(2,0)^{\mathsf T}$ U 开始，沿逆时针转动又逐渐靠近原点的轨迹。要写出它的两个坐标，先从圆上的位置建立正弦、余弦与角度的联系。

单位圆、弧度与正弦余弦

以原点为圆心、半径为 1 画圆。从正横轴出发，沿逆时针转到圆上一点，用角度 $\theta$ 标记转过的位置。角度的弧度（radian）定义为所经过弧长与半径的比；它是无量纲数。转一圈经过圆周 $2\pi$，所以一圈是 $2\pi$ 弧度，半圈是 $\pi$，四分之一圈是 $\pi/2$。

这个单位圆点的横坐标定义为余弦（cosine） $\cos\theta$，纵坐标定义为正弦（sine） $\sin\theta$。于是

$$\cos^2\theta+\sin^2\theta=1,$$

直接来自圆的半径为 1。几个位置可以先手算：

转过的位置 $\theta$ $\cos\theta$ $\sin\theta$
起点 0 1 0
四分之一圈 $\pi/2$ 0 1
半圈 $\pi$ $-1$ 0
四分之三圈 $3\pi/2$ 0 $-1$
一圈 $2\pi$ 1 0

半径为 $R$、起点在正横轴的点，坐标就是 $(R\cos\theta,R\sin\theta)$。一般起点 $(x_{10},x_{20})$ 转过 $\theta$ 后，两个原坐标方向分别转到 $(\cos\theta,\sin\theta)$ 和 $(-\sin\theta,\cos\theta)$，因此新坐标为

$$\begin{pmatrix}x_1\\x_2\end{pmatrix} =\begin{pmatrix}\cos\theta&-\sin\theta\\\sin\theta&\cos\theta\end{pmatrix} \begin{pmatrix}x_{10}\\x_{20}\end{pmatrix}.$$

例如 $[2,1]$ U 转过四分之一圈后，变为 $[-1,2]$ U。两坐标改变了，平方和仍为 5 U²。

旋转还给出三角函数的变化率。当单位圆上的点转过很小的 $\Delta\theta$，走过的弧长就是 $\Delta\theta$，运动方向沿圆的切线；位置 $(\cos\theta,\sin\theta)$ 对应的单位切向为 $(-\sin\theta,\cos\theta)$。取变化率极限，得到

$$\frac{d\cos\theta}{d\theta}=-\sin\theta,\qquad \frac{d\sin\theta}{d\theta}=\cos\theta.$$

若角度为 $\theta=\omega t$，链式法则再带来一个 $\omega$。$\omega$ 称为角频率，单位为 $1/\mathrm T$；经过时长 $t$，转过角度 $\omega t$。

复数、共轭与欧拉公式

两个实坐标可以合写成复数（complex number）

$$z=x_1+i x_2,\qquad i^2=-1.$$

$i$ 称为虚数单位；$x_1$ 是实部，$x_2$ 是虚部。两者仍是原来的实数偏差。复数相加分别加实部、虚部；相乘时按普通分配律展开，并用 $i^2=-1$ 合并。例如

$$i(x_1+i x_2)=-x_2+i x_1.$$

乘一次 $i$，恰好把坐标转为 $(-x_2,x_1)$，也就是逆时针四分之一圈。从 $1$ 开始连续乘 $i$，依次得到 $1,i,-1,-i,1$，四次后回到起点。Python 用 j 书写这个虚数单位。

共轭（complex conjugate） $\bar z=x_1-i x_2$ 反转虚部符号；二者相乘得到 $z\bar z=x_1^2+x_2^2$。因此复数的模（modulus）

$$|z|=\sqrt{x_1^2+x_2^2}$$

正是状态到原点的距离。表示任意旋转的单位复数为 $\cos\theta+i\sin\theta$；将它乘 $z$ 并展开，就会得到上一段的旋转矩阵公式。

复数指数与这个旋转由欧拉公式（Euler's formula）联系：

$$\boxed{e^{i\theta}=\cos\theta+i\sin\theta.}$$

指数的幂级数可以同样用于复数。$e^{i\theta}$ 对 $\theta$ 求导为 $ie^{i\theta}$，起点为 1；右边求导得到 $-\sin\theta+i\cos\theta=i(\cos\theta+i\sin\theta)$，起点也为 1。二者描述同一个从正横轴出发的单位速率旋转。

阻尼旋转的实数方程与解

让旋转以角频率 $\omega$ 进行，同时让长度以速率 $\alpha$ 指数衰减。取 $\alpha\ge0$，方程可合写成

$$\dot z=(-\alpha+i\omega)z.$$

右边展开为

$$(-\alpha+i\omega)(x_1+i x_2) =(-\alpha x_1-\omega x_2)+i(\omega x_1-\alpha x_2).$$

所以两个实数坐标满足

$$\dot x_1=-\alpha x_1-\omega x_2,\qquad \dot x_2=\omega x_1-\alpha x_2,\qquad M=\begin{pmatrix}-\alpha&-\omega\\\omega&-\alpha\end{pmatrix}.$$

交叉项一负一正，产生旋转；两个对角项让状态一起向原点缩小。结合指数解与欧拉公式，得

$$z(t)=e^{-\alpha t}(\cos\omega t+i\sin\omega t)z(0).$$

令 $x_{10}=x_1(0)$、$x_{20}=x_2(0)$，分别读取实部与虚部：

$$\boxed{\begin{aligned} x_1(t)&=e^{-\alpha t}(x_{10}\cos\omega t-x_{20}\sin\omega t),\\ x_2(t)&=e^{-\alpha t}(x_{10}\sin\omega t+x_{20}\cos\omega t). \end{aligned}}$$

$\alpha,\omega$ 的单位均为 $1/\mathrm T$，所以指数与三角函数的自变量无量纲。若初值为 $[2,0]$ U，$\alpha=0.2/\mathrm T$、$\omega=1/\mathrm T$，转过四分之一圈的时刻是 $t=\pi\mathrm T/2$。此时第一分量为零，第二分量为

$$2e^{-0.2\pi/2}\ \mathrm U\approx1.461\ \mathrm U.$$

到半圈时，第一分量为负、第二分量为零；偏差已经转到了参考点的另一侧，长度却比起点小。

左图的两条实数曲线交替过零，右图将相同时刻合成一点，显示逆时针向内的轨迹。右图每隔 1 T 标点，横纵坐标同尺度。把两条公式平方后相加，交叉项消去，得到

$$x_1(t)^2+x_2(t)^2=e^{-2\alpha t}(x_{10}^2+x_{20}^2).$$

当前半径恰为 $2e^{-0.2t/\mathrm T}$ U。某个分量可以暂时离零更远，但两者合起来的距离持续缩小。$\alpha=0$ 时只有旋转，$\omega=0$ 时只有衰减；两个参数都为零时保留初值。

共轭特征值与两室交换的区别

对阻尼旋转矩阵，特征方程为

$$\det(M-\lambda I)=(\lambda+\alpha)^2+\omega^2=0,$$

解为 $\lambda_+=-\alpha+i\omega$、$\lambda_-=-\alpha-i\omega$。实部 $-\alpha$ 控制长度衰减，虚部 $\pm\omega$ 记录这对旋转模态。可以直接相乘核对其特征向量：

$$v_+=\begin{pmatrix}1\\-i\end{pmatrix},\qquad v_-=\begin{pmatrix}1\\i\end{pmatrix},\qquad Mv_\pm=\lambda_\pm v_\pm.$$

两者互为共轭。实矩阵的非实特征值成共轭对：把 $Mv=\lambda v$ 取共轭时，矩阵仍是 $M$，所以 $M\bar v=\bar\lambda\bar v$。对实初值，这一对复模态共同产生前面的实数轨迹。

$\omega>0$ 时转一圈需要 $2\pi/\omega$；若同时有 $\alpha>0$，转完一圈的长度缩短，整条状态轨迹就不会周期性返回同一点。

回到只有双向交换、没有外部输入和清除的两室总量模型，其特征方程为

$$\det\begin{pmatrix}-a-\lambda&b\\a&-b-\lambda\end{pmatrix} =\lambda(\lambda+a+b)=0.$$

两个特征值为 0 与 $-(a+b)$，都为实数。给定总量 $S$ 且 $a+b>0$ 时，第一室相对平衡的偏差满足

$$A_1(t)-A_1^*=[A_1(0)-A_1^*]e^{-(a+b)t},\qquad A_1^*=\frac{bS}{a+b}.$$

第二室偏差与它相反。若两条通道都关闭，即 $a=b=0$，两室分别保持初值。正的指数因子保持偏差符号，因此两室不会反复越过各自平衡。增大回流系数 $b$ 会改变平衡分配，却不会把这套收支变成阻尼旋转。能否出现往复变化，应由具体作用关系解释。

特征向量不足与上三角系统

上一节的对角化需要两个独立方向。现在考虑有符号偏差模型

$$\dot x=Mx,\qquad M=\begin{pmatrix}-r&q\\0&-r\end{pmatrix},\qquad \dot x_1=-rx_1+qx_2,\quad \dot x_2=-rx_2.$$

$r,q$ 的单位均为 $1/\mathrm T$。这个矩阵的主对角线下方元素为零，称为上三角矩阵（upper triangular matrix）。特征方程为 $(\lambda+r)^2=0$，两个特征值都为 $-r$；当 $q\ne0$ 时，特征向量条件给出

$$(M+rI)v=\begin{pmatrix}qv_2\\0\end{pmatrix}=0,$$

只能有 $v_2=0$。所有特征向量都沿第一坐标方向，因此无法用两个独立特征向量组成基。这是 Jordan 块（Jordan block）的一种缩放写法。

原方程仍可以依次求解。先从第二式得到 $x_2(t)=x_{20}e^{-rt}$，再代入第一式：

$$\dot x_1+rx_1=q x_{20}e^{-rt}.$$

两边乘 $e^{rt}$，用乘积求导把左边合起来：

$$\frac d{dt}(e^{rt}x_1)=e^{rt}(\dot x_1+rx_1)=q x_{20}.$$

从 0 到 $t$ 积分，得到 $e^{rt}x_1(t)-x_{10}=qtx_{20}$，所以

$$\boxed{x_1(t)=e^{-rt}(x_{10}+qtx_{20}),\qquad x_2(t)=e^{-rt}x_{20}.}$$

$q t$ 无量纲。额外的 $t e^{-rt}$ 项记录了第二分量持续推动第一分量的作用；仅把相同指数写两遍会漏掉它。

取 $r=q=1/\mathrm T$、初值 $[0,1]$ U，令 $\tau=t/\mathrm T$：

$$x_1=\mathrm U\,\tau e^{-\tau},\qquad x_2=\mathrm U\,e^{-\tau}.$$

$t/\mathrm T$ $x_1$/U $x_2$/U
0 0 1
1 $e^{-1}\approx0.3679$ $e^{-1}\approx0.3679$
2 $2e^{-2}\approx0.2707$ $e^{-2}\approx0.1353$
3 $3e^{-3}\approx0.1494$ $e^{-3}\approx0.0498$

第一分量导数为 $(\mathrm U/\mathrm T)(1-\tau)e^{-\tau}$，在 $t=1$ T 前为正、之后为负，所以先升后降。两个负特征值给出这组解的长期衰减，却没有让每个分量都从起点开始单调下降。

若 $q=0$，矩阵为 $-rI$，两个坐标方向都是特征向量，重复特征值并不妨碍对角化；若 $r=0$，第二分量保持不变，第一分量线性变化。按实际方程与独立方向判断，才能选择合适的求解方式。
