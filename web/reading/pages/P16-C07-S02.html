16.7.2 配对评价、动作超限与求解失败

两个预测器用于相同调节任务，哪一个更合适？上一节已经看到，预测、动作选择与实际状态各有自己的记录。现在把两种方法放到同一组场景中，分别计算这些记录所反映的结果。

学完本节，你应能按场景配对计算误差差值，手算预测RMSE、动作平方均值和两个比例，并说明失败场景使用了什么最终记录。先修为16.7.1及第14篇的独立预测比较。

场景配对与误差差值

配对比较（paired comparison）让两种方法在相同场景上逐项对应。若第 $i$ 项表示某个共同初态和输入条件，这个含义在两份列表中保持不变。

例如三个场景的绝对误差为 $[0.1,0.2,0.3]$ U与 $[0.2,0.1,0.5]$ U。按第一种减第二种，得到

$$d=[-0.1,0.1,-0.2]\ \mathrm U.$$

负值表示第一种方法在该场景误差更小，正值表示第二种更小。第一与第三场景有利于第一种，第二场景则相反。逐场景的差保留了这种变化；将两个列表各自排序再相减，会打乱原来的对应。

预测、动作与失败的完整记录

下面使用预先给定的五场景记录，练习评价计算。真实后继状态记为 $x_i$，机制方法和学习方法各有一个预测 $\hat x_i$、实际动作 $u_i$和求解失败标记 $f_i$。失败标记为1表示本次求解失败，0表示未失败。

场景 真实状态 / U 机制预测 / U 学习预测 / U 机制动作 / U 学习动作 / U 机制失败 学习失败
1 1.0 0.9 1.00 0.1 0.2 0 0
2 0.8 0.9 0.80 0.2 0.4 0 0
3 1.2 1.1 1.19 0.1 0.1 0 0
4 1.1 1.0 1.05 0.2 0.6 0 1
5 1.4 1.2 1.45 0.1 0.2 0 0

规定动作上限为0.5 U。这组记录在求解失败后仍提供了最终预测与实际动作，因此第四行也有可以评价的误差与输入。失败标记继续保留，描述求解可靠性；实际动作则记录最终执行了什么。

若需要比较两个完整控制方案，还应固定可用观测、训练与调参预算、允许动作和失败后的处理。先确定这些共同条件，再在同一组评价场景上记录结果，逐项比较。

四项指标及其单位

令共同场景数为 $N$，定义

$$E_x=\sqrt{\frac1N\sum_{i=1}^N(x_i-\hat x_i)^2},\qquad C_u=\frac1N\sum_{i=1}^N u_i^2.$$

$E_x$是预测均方根误差，单位U；$C_u$是动作平方均值，单位U²，反映这组任务中动作的大小。再定义

$$F_u=\frac1N\sum_{i=1}^N\mathbf1(|u_i|>u_{\max}),\qquad F_{\mathrm{fail}}=\frac1N\sum_{i=1}^N f_i.$$

指示函数 $\mathbf1(\cdot)$ 在条件成立时取1，否则取0。$F_u$为动作超限比例，$F_{\mathrm{fail}}$为求解失败比例，二者无量纲。动作恰好等于上限时符合要求，故使用严格大于号。

这里 $F_u$检查实际动作；上一节的实际状态上界是另一项检查。指出哪个量超过哪条限制，才能把问题定位到执行量或状态。

计算题的返回列表按 $[E_x,C_u,F_u,F_{\mathrm{fail}}]$ 排列。它们分别回答预测、动作大小、动作约束和求解可靠性的问题。

五场景的逐项手算

机制预测误差的平方为 $[0.01,0.01,0.01,0.01,0.04]$ U²，总和0.08 U²，所以

$$E_{x,\mathrm{mech}}=\sqrt{0.08/5}\approx0.126491\ \mathrm U.$$

机制动作平方和为 $0.01+0.04+0.01+0.04+0.01=0.11$ U²，均值0.022 U²；没有动作超限或求解失败，两个比例均为0。

学习方法的预测误差平方和为

$$0+0+0.0001+0.0025+0.0025=0.0051\ \mathrm U^2,$$

因此RMSE约0.031937 U。动作平方和为 $0.04+0.16+0.01+0.36+0.04=0.61$ U²，均值0.122 U²。第四场景的0.6 U动作超过上限，且该行求解失败，两个比例分别为 $1/5=0.2$。

图按四个指标分别比较两种方法。学习方法的预测误差较小，同时使用了更大的动作；五个场景中有一个动作超限，并保留了一次求解失败。这些是同一次比较的不同结果，各自保留单位和分母。

失败场景与统计分母

如果删去第四行，两个比例都会从 $1/5$ 变为0，预测与动作统计也改成了剩余四个场景。变化来自评价对象被删掉，而非方法解决了这次失败。

本题给出了失败后的有效最终预测与执行记录，故四指标都使用全部场景。实际评价中，要先确定失败后记录的含义：有最终输出时可以评价它的误差，同时保留失败标记；若根本没有有效预测，就需要另报可比场景数及失败率。

例如题目给定两场景预测完全等于真值，动作是 $[0.1,1.5]$ U、上限1 U，失败标记为 $[0,1]$。其RMSE为0，动作平方均值为 $(0.01+2.25)/2=1.13$ U²，两个比例均为 $1/2$。数值不同，计算与记录原则相同。

从记录回到控制问题

更小的预测误差说明预测在这些场景中更接近实际结果；动作平方、动作超限和求解失败则继续描述执行与选择的表现。将它们逐项放回共同场景，就能看出改进出现在哪里、还需要处理哪一部分。

本篇从实际输入出发，依次建立下降条件、模型集合、估计时序、随机路径、局部通信和策略价值。篇末综合将选取其中的小例，要求把每项计算接回它的对象与条件。
