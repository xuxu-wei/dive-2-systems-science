17.1.1 Lorenz方程与稀疏候选字典

一条弯曲的轨迹可能由许多不同的方程产生。如果希望从记录中找回运动规律，就要把“曲线看起来相像”变成更具体的问题：变化率由哪些项组成，各项的系数是多少，换一个起点后还预测得怎样？本篇从Lorenz系统开始，把第14篇的稀疏辨识接到原始研究的一个实例上。

学完本节，应能代入三条方程计算变化率，说明状态表、候选字典和系数表的行列含义，并把当前数据对应到要检验的问题。先修为4.6的Lorenz系统、14.4的稀疏动力学辨识，以及第6篇的最小二乘。

Lorenz方程与瞬时变化率

记三维状态为$\mathbf s=(x,y,z)^{\mathsf T}$。状态和时间都采用归一化的无量纲数值，方程为

$$\begin{aligned} \dot x&=\sigma(y-x),\\ \dot y&=x(\rho-z)-y,\\ \dot z&=xy-\beta z. \end{aligned}$$

沿用$\sigma=10,\rho=28,\beta=8/3$。点号表示对归一化时间求导；给定当前位置，方程就给出此刻的运动方向和快慢。

从$\mathbf s_0=(-8,7,27)^{\mathsf T}$出发，逐项代入：

$$\begin{aligned} \dot x_0&=10[7-(-8)]=150,\\ \dot y_0&=(-8)(28-27)-7=-15,\\ \dot z_0&=(-8)\times7-\frac83\times27=-56-72=-128. \end{aligned}$$

所以变化率按$x,y,z$的顺序是$[150,-15,-128]$。其中150表示$x$此刻增加得很快；它是导数，推进到下一时刻还需要积分。返回列表时也要保持这个坐标顺序。

候选字典与系数的位置

SINDy把变化率写成一组候选函数的线性组合，再寻找其中少量起作用的项。这里的“线性组合”指对系数线性：候选函数本身可以是$xy$、$xz$等非线性函数。

将当前状态展开为一行二次候选项：

$$\boldsymbol\theta(\mathbf s)= [1,x,y,z,x^2,xy,xz,y^2,yz,z^2].$$

常数1允许方程含有与状态无关的项；三个一次项之后，按固定顺序放入六个二次项。起点对应

$$\boldsymbol\theta(\mathbf s_0) =[1,-8,7,27,64,-56,-216,49,189,729].$$

例如$xy=-56$，$xz=-216$，而$y^2=49$。计算题用状态$[2,3,4]$练习同一顺序，返回$[1,2,3,4,4,6,8,9,12,16]$。位置固定后，每个系数才能始终乘到同一种函数上。

把所有采样时刻的状态按行排列，记作$X$；每行展开后得到候选字典矩阵$\Theta(X)$。将三个变化率也按行排列，记作$\dot X$。系数表$\Xi$的行对应候选项、列对应三条方程，于是

$$\dot X\approx\Theta(X)\Xi.$$

已知Lorenz方程在这十列中的系数如下：

$z$ 0 0 $-8/3$
$x^2$ 0 0 0

表中有$10\times3=30$个系数位置，其中7个非零。例如第二列给出$\dot y=28x-y-xz$；在起点就是$28\times(-8)-7-(-216)=-15$。这与直接代入原方程相同，也说明交叉项的符号为什么不能随意交换。

稀疏恢复要从数据估计这张表。找对非零项回答“用了哪些函数”，估准其数值回答“各项作用有多强”；两者可以分别比较。

采样窗口与状态覆盖

用RK4从上述初态推进，取间隔$h=0.01$，保留归一化时间$0$到4的状态。更新次数为$4/0.01=400$，加上起点，共有401行。因此

$$X:\ 401\times3,\qquad \Theta(X):\ 401\times10,\qquad \Xi:\ 10\times3.$$

下面画出这段轨迹的$x$、$z$坐标。

横轴是$x$，纵轴是$z$，蓝线随时间依次连接采样状态。这幅投影展示轨迹经过的状态区域；时间并没有放在某条坐标轴上。展开字典时，每个点都贡献一行，而不是把这张二维图当作拟合数据。

数据行数多，表示记录了更多时刻；能否区分候选项，还取决于轨迹经过哪里。例如两个候选列在当前轨迹上总是接近成比例时，最小二乘就难以分别确定它们的系数。这与第6篇的参数辨识问题相同。

精确导数与方程恢复问题

生成状态后，把每行$\mathbf s_n$代回已知方程，便得到同一时刻的精确变化率$\dot{\mathbf s}_n$。这里的“精确”指方程右端在给定状态上的函数值；状态轨迹仍由RK4数值积分产生。

这样可以先研究候选函数和稀疏拟合本身。若拿到的是带噪状态读数，则还要估计导数：例如差分会用两个读数之差除以时间间隔，测量噪声也随之被放大。当前由方程提供导数，正好将这个环节与后面的系数筛选分开。

原研究配置与当前计算

SINDy论文的v1版本以同一个Lorenz方程和初态研究方程发现，使用更长的记录和更宽的字典。把两项规模放在一起看：

行数由区间和间隔算得。按总次数分别计数，常数到二次共有$1+3+6=10$列；继续加入三、四、五次项，则为$1+3+6+10+15+21=56$列。窗口增加主要让数据表变高，次数增加让字典变宽。原论文还研究了导数噪声下的恢复与较长时间的轨迹；本篇从精确导数开始，先把十列字典中的恢复过程逐步算清。
