5.2.2 联合分布、协方差与共享偏移

学完本节，你应能从成对概率表判断独立性，计算两个量相加后的波动，并解释共同偏移为什么会留在多次测量的平均里。

先修知识：期望、方差、独立平均，以及第 3 篇的向量和矩阵。

联合分布与边缘分布

两台仪器若总在同一次测量中一起偏高，它们相加后的波动会怎样？单独给出每台仪器的方差，还没有保留“一起”这一信息。我们需要记录成对结果。

先看一个便于手算的关系：$X$ 等概率取 $-1,0,1\,\mathrm U$，并令 $Y=X^2$，因此 $Y$ 的单位为 U²。三种可能的数对为

$$(-1\,\mathrm U,1\,\mathrm{U^2}),\quad (0\,\mathrm U,0\,\mathrm{U^2}),\quad (1\,\mathrm U,1\,\mathrm{U^2}).$$

两个变量同时取给定值的概率构成联合分布（joint distribution）。记

$$p_{ij}=P(X=x_i,Y=y_j),$$

把 $X$ 放在行、$Y$ 放在列，本例的概率表为

$X$/U 与 $Y$/U² $Y=0$ $Y=1$ 行和
$X=-1$ 0 $1/3$ $1/3$
$X=0$ $1/3$ 0 $1/3$
$X=1$ 0 $1/3$ $1/3$
列和 $1/3$ $2/3$ 1

若只关心 $X$，将每行所有 $Y$ 的可能性加起来；若只关心 $Y$，将每列加起来。这两种单变量分布称为边缘分布（marginal distribution），分别为

$$p_X(x_i)=\sum_jp_{ij},\qquad p_Y(y_j)=\sum_ip_{ij}.$$

上节的独立乘积规则在联合表里变得很具体：两个离散变量独立，当且仅当每个格子都满足

$$p_{ij}=p_X(x_i)p_Y(y_j).$$

本例中央格的概率是 $1/3$，行概率乘列概率却是 $1/3\times1/3=1/9$，因此 $X,Y$ 不独立。知道 $Y=0$ 就能确定 $X=0$，也直观地显示两者互相提供了信息。

协方差与非线性依赖

若想用一个数描述两量偏离各自中心时是否同向，可以将中心偏差相乘，再按联合分布求平均。这个量称为协方差（covariance）：

$$\operatorname{Cov}(X,Y) =\mathbb E[(X-\mu_X)(Y-\mu_Y)],\qquad \mu_X=\mathbb E[X],\quad\mu_Y=\mathbb E[Y].$$

两者同时偏高或同时偏低，乘积为正；一个偏高、另一个偏低，乘积为负。展开后得到

$$\operatorname{Cov}(X,Y)=\mathbb E[XY]-\mu_X\mu_Y.$$

对上面的三点关系，$\mu_X=0\,\mathrm U$、$\mu_Y=2/3\,\mathrm{U^2}$。逐项计算：

$X$/U $Y$/U² 中心乘积 / U³ 概率加权后的贡献 / U³
$-1$ 1 $-1/3$ $-1/9$
0 0 0 0
1 1 $1/3$ $1/9$

正负贡献相消，所以协方差为零。协方差为零称为不相关（uncorrelated）；本例已经由联合表确认存在依赖，却仍不相关。协方差保留了中心乘积的平均，而平方关系在左右两端产生相反贡献。

独立且二阶矩有限时，$\mathbb E[XY]=\mathbb E[X]\mathbb E[Y]$，因此一定不相关；三点关系展示了逆向推理为何不成立。

成对数据的协方差

对于两通道已经记录的 $n$ 对读数 $(x_i,y_i)$，先分别求平均 $\bar x,\bar y$。描述这组记录的协方差为

$$s_{xy,n}=\frac1n\sum_{i=1}^{n}(x_i-\bar x)(y_i-\bar y).$$

这里沿用描述性方差的分母 $n$。配对顺序很重要：$x_i$ 和 $y_i$ 必须来自同一次观察。分别打乱两个列表，会改变中心偏差怎样配对，从而改变协方差。

例如两通道读数分别为 $[0,1,2]\,\mathrm U$、$[2,1,0]\,\mathrm U$，两个平均都为 $1\,\mathrm U$。各自方差都为 $2/3\,\mathrm{U^2}$，协方差为

$$\frac{(-1)(1)+0\times0+(1)(-1)}3 =-\frac23\,\mathrm{U^2}.$$

一个通道升高时，另一个等量降低，中心偏差的乘积始终非正。下一步可以检验，这种对应关系是否足以让两通道之和保持不变。

和的方差与相关系数

令两个中心偏差分别为 $X-\mu_X$、$Y-\mu_Y$，相加后平方，再求期望，得到

$$\boxed{\operatorname{Var}(X+Y) =\operatorname{Var}(X)+\operatorname{Var}(Y)+2\operatorname{Cov}(X,Y).}$$

代入刚才的配对记录，描述性方差同样满足

$$\frac23+\frac23+2\left(-\frac23\right)=0.$$

逐对相加确实总为 $2\,\mathrm U$。若漏掉协方差，就会给一个恒定总和算出非零波动。相反，两个中心偏差常常同向时，正协方差会增加总和的方差。

协方差的单位是两个变量单位的乘积。要用无单位的数描述线性关联，可将它除以两边的标准差，得到相关系数（correlation coefficient）

$$\rho=\frac{\operatorname{Cov}(X,Y)}{\sigma_X\sigma_Y},\qquad \sigma_X>0,\quad\sigma_Y>0.$$

刚才两通道的相关系数为 $-1$。若一个通道在整组记录中恒定，其标准差为零，分母也为零，相关系数就没有定义；协方差仍可计算，并且为零。

  • 计算恒定通道的相关

对于多个变量，协方差矩阵（covariance matrix） $\Sigma$ 将 $\operatorname{Cov}(X_i,X_j)$ 放在第 $i$ 行、第 $j$ 列，对角线上就是各自方差。若按相同顺序排列变量向量 $\boldsymbol X$ 与常数权重 $\boldsymbol c$，组合量的方差为

$$\operatorname{Var}(\boldsymbol c^T\boldsymbol X) =\boldsymbol c^T\Sigma\boldsymbol c\ge0.$$

它就是刚才两量相加公式的多变量版本：每个方差按权重平方贡献，每对协方差按对应两权重的乘积贡献。

共享偏移为何留在平均中

现在回到重复测量。设同一真值为 $\theta=1\,\mathrm U$，一组内第 $i$ 次读数为

$$Y_i=\theta+B+V_i.$$

每组开始时抽一次共同偏移 $B$，组内所有读数沿用它；每次测量另抽一个误差 $V_i$。设 $B\sim N(0,B_0)$，$V_i\sim N(0,R)$，各个 $V_i$ 相互独立，并与 $B$ 独立。这里 $B_0,R$ 是方差，单位都是 U²。

每次读数的方差为 $B_0+R$，不同读数之间却保留共同的 $B$。对 $i\ne j$，

$$\operatorname{Cov}(Y_i,Y_j) =\mathbb E[(B+V_i)(B+V_j)] =\mathbb E[B^2]=B_0,$$

其余三项因独立且均值为零而消失。再把一组的 $n$ 次读数平均：

$$\bar Y-\theta=B+\frac1n\sum_iV_i.$$

独立误差按前节规律缩小，共同偏移则每次出现相同的值，平均后仍为 $B$。因此

$$\boxed{\operatorname{Var}(\bar Y-\theta)=B_0+\frac Rn.}$$

取 $B_0=0.04\,\mathrm{U^2}$、$R=0.09\,\mathrm{U^2}$，每组测量 5、50、500 次时，理论方差依次为

每组测量数 $n$ 独立误差贡献 $R/n$ / U² 总方差 / U²
5 0.018 0.058
50 0.0018 0.0418
500 0.00018 0.04018

下图左侧保留前面的平方关系，右侧对每种测量数重复 200 组，将组平均的经验方差与公式比较。每一组重新抽共同偏移，才能观察这个偏移在组与组之间带来的变化。

随着测量数增加，理论曲线逐渐靠近灰色的 $B_0$ 水平。蓝色经验点来自每种条件下有限的 200 组结果，还会随抽样波动；图中测量 500 次的经验方差略高于 50 次，两个理论方差则分别为 0.04018、0.0418 U²。多测几次能减小每次重抽的误差，却不能校正这一组始终相同的偏移。要继续提高精度，应增加对偏移本身的认识，例如用参考样本校准仪器。
