学完本节，你应能连接输入区间与采样模型，按误差尺度比较参数候选，并将数据划分、预测评分和在线更新按正确顺序组合起来。

先修知识：本篇六章的采样、系统表示、最小二乘、动态回归和递推辨识。

观测计划与可见动态

两组培养室记录分别描述停供后的清除和持续刺激下的动态响应。前者用于比较清除参数，后者用于比较预测方式。连接它们时，先确认每一列记录代表什么、每一个时间间隔怎样进入模型。

例如节律同时含0.2 Hz与0.8 Hz余弦，每秒采一次。在整数时刻 $n$，

$$\cos(2\pi\,0.8n) =\cos(2\pi n-2\pi\,0.2n) =\cos(2\pi\,0.2n).$$

这份采样已经把两种连续频率映成相同记录。求解器内部用0.001 s还是更小步长，不改变原来每秒一次的观测时刻。增加采样率则改变能看到的时间信息；在相应带限和理想采样条件下，采样率高于1.6 Hz可以分开这两个频率。

在线滤波也要对应实际时钟。居中平均需要等待后续读数到达；已有记录的补零只改变频谱计算的格点，不会补回此前没有测到的变化。

区间输入与离散响应

令所追踪物质总量为 $A$，单位U，输入流率为 $q$，单位U/T，满足

$$\dot A=q-kA,\qquad k\ge0.$$

这里用 $q$ 表示流率，后面的刺激输入另记为 $u$，单位V。每个长度为 $h$ 的区间内流率保持不变，6.3的区间积分给出

$$A_{n+1}=aA_n+bq_n,\qquad a=e^{-kh},\qquad b=\int_0^he^{-k\tau}\,d\tau.$$

所以 $k>0$ 时 $b=(1-e^{-kh})/k$，$k=0$ 时 $b=h$。$a$ 无单位，$b$ 的单位为T，乘流率后得到U。

Euler则只用区间起点变化率：

$$A_{n+1}=(1-kh)A_n+hq_n.$$

取 $k=0.25/\mathrm T,h=2\,\mathrm T,A_0=2\,\mathrm U,q_0=1\,\mathrm{U/T}$，精确更新为

$$A_1=2e^{-0.5}+4(1-e^{-0.5}) =4-2e^{-0.5}\approx2.78694\,\mathrm U,$$

Euler得到 $A_1=2+2(1-0.25\times2)=3$ U。两种序列随后都使用各自上一项，才能比较两个不同更新规则的累积差异。

若采样间隔改变，应重新计算状态保留系数和区间输入累计系数。例如 $k=0.4/\mathrm T$、间隔从1 T改为2 T，新的两项为

$$a=e^{-0.8},\qquad b=\frac{1-e^{-0.8}}{0.4/\mathrm T}.$$

改变间隔不仅让状态多衰减一段时间，也让恒定输入多作用一段时间。

参数候选与加权残差

停供后的另一组记录在0、1、2 T测得5、3、2 U，初始总量独立给定为5 U。候选为 $k=0,0.5,1/\mathrm T$。对每个候选计算

$$p_i(k)=5\,\mathrm U\,e^{-kt_i},\qquad r_i(k)=y_i-p_i(k),\qquad S(k)=\sum_iw_i r_i(k)^2.$$

本综合采用逆误差方差作为权重，数值1、2、1的单位为 $1/\mathrm{U^2}$，对应测量标准差1、$1/\sqrt2$、1 U，故损失无单位。它与6.4中无单位相对权重的计算有相同形式，但损失单位不同。

候选 $k$ / (1/T) 预测 / U 加权平方损失
0 $[5,5,5]$ 17
0.5 $[5,5e^{-0.5},5e^{-1}]$ 约0.027926
1 $[5,5e^{-1},5e^{-2}]$ 约4.445183

候选0.5/T胜出。它在这个有限集合中使给定损失最小；若要比较其他参数，需要把它们的预测也放进同一个目标中。独立高斯测量误差下，这个损失对应相应的负对数似然中的残差部分。

激励、未知量与独立方程

连续曲线拟合给参数规定了物理关系。若换成两个自由系数的ARX模型，能够识别什么还要重新判断。

在非零恒定输入的同一稳态重复读数，只重复约束

$$y^*=ay^*+bu^*.$$

即使读1000次，回归行仍全为 $[y^*,u^*]$，无法分开不同的 $a,b$ 组合。记录可见瞬态或改变输入后，再检查新回归列是否线性独立，才能判断是否增加了区分参数的方向。

时间划分与训练预处理

以短记录检算划分：时刻为0、1、2、3、4、5 T，读数为1、3、缺测、5、7、9 U。设训练到2 T之前，验证到4 T之前，得到

用途 有效原索引 读数 / U
训练 $[0,1]$ $[1,3]$
验证 $[3]$ $[5]$
最终 $[4,5]$ $[7,9]$

训练均值为2 U，按训练点数作分母的尺度为1 U。对所有有效读数使用同一变换后，原位置的标准化结果为

$$[-1,1,\text{缺测},3,5,7].$$

缺测占位不删除，原索引不改写；需要上一拍的动态回归行还要确认那一拍确实存在。训练尺度若为零，本题按所用数值单位将除数设为1。验证和最终段的读数怎样变化，都不影响这对训练统计量。

两种预测与共同评分目标

回到持续刺激的短记录。现在输入 $u$ 单位为V，读数 $y$ 单位为U，已固定 $a=0.5,b=1$ U/V。读数 $[0,1,2,2]$ 对应时刻0—3，输入 $[1,1,0]$ 对应三个区间。

目标时刻 观测 / U 一步预测 / U 自由运行 / U
1 1 1 1
2 2 1.5 1.5
3 2 1 0.75

一步预测使用每拍的新观测，自由运行只读取共同初态。两种结果都对后面的三个目标评分，共同起点不加入误差。因此一步平方误差和为 $0+0.25+1=1.25$，自由运行是 $0+0.25+1.5625=1.8125$，RMSE分别为

$$\sqrt{\frac{1.25}3}\approx0.6455\,\mathrm U,\qquad \sqrt{\frac{1.8125}3}\approx0.7773\,\mathrm U.$$

递推选择与在线评估

若参数缓慢变化，可进一步按6.6的指数权重更新。为了检算顺序，取四条无单位读数 $[0,0,2,2]$，特征均为1，初始参数0、逆信息1，候选因子为1与0.5。数组索引1、2用于调参，索引3用于最终在线评分。

两个候选在调参目标到来前都预测0，因此调参均方误差同为 $(0^2+2^2)/2=2$，按并列规则选择0.5。对所选因子，按记录数展开批量累计量：

数组索引 当前读数 更新前预测 新信息 $H$ 更新后参数
0 0 0 $3/2$ 0
1 0 0 $7/4$ 0
2 2 0 $15/8$ $16/15$
3 2 $16/15$ $31/16$ $48/31$

第3索引的读数尚未到达时，能使用的参数是 $16/15$。因此留出误差为 $2-16/15=14/15$，只有一个目标时RMSE也是 $14/15$。使用这条读数更新后，参数才变为 $48/31$，用于此后的预测。
