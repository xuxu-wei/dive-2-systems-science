## 2. 各章内容、实验与练习

### 13.1 相变、临界性与有限规模

- **直接先修**：12.5、4.3、6.4；数学：数11、数24。
- **教学目标**：由个体取值形成序参量，比较时间汇总和重复波动，并解释确定性边界与有限曲线的关系。
- **教学重难点**：先取绝对值再汇总，避免正负方向抵消；一步条件方差、重复间标准差和均值不确定性具有不同含义。
- **内容顺序**：①有符号平均与一致程度的手算；②双曲正切概率、条件独立更新和一步条件矩；③重复汇总、确定性零点稳定性与多规模参数扫描。
- **核心实验**：第一节固定beta=1.2、N=50/200/800，各12次重复和120次更新，保留下标40—120的81项。第二节在同三规模上扫描0.7/0.9/1/1.1/1.3，各10次重复，保留50—120的71项。误差棒和打印标准差均描述重复间离散程度，除数为重复次数。
- **练习 E1（选择题）**：区分有符号均值与幅度、推导有限平均方差，判断何种重复和规模证据可支持临界变化。
- **练习 E2（计算题）**：先在每条保留轨迹内求平均幅度，再返回重复均值和标准差；另实现确定性双曲正切映射并保留起点。
- **练习 E3（选择题）**：由零点导数解释确定性稳定性变化，检查初值、暂态、时长及规模比较，避免从有限曲线直接宣称无限规模阈值或普适指数。
- **核验与反馈**：核对给定随机数的一步更新、条件方差和中心差分导数。确定性平均映射不等于逐时刻平均有限重复；虚线beta=1来自解析导数，扫描图只有五个给定参数点。
- **编写参考**：R12、R13（资料与主题对应见本篇末表）。


### 13.2 级联失效与结构鲁棒性

- **直接先修**：13.1、11.3；数学：数21、数24。
- **教学目标**：逐轮区分直接损伤与继发失效，再把最终失效集合与剩余连通规模分开评价。
- **教学重难点**：累计集合用于触发，返回名单只记录本轮新增；功能代理需说明分母和真实容量未被建模。
- **内容顺序**：①四节点链的同步名单；②正整数阈值、无初始损伤及停止条件；③同节点数和边数的链与星；④单独提高阈值并比较可用分量。
- **核心实验**：六节点链从0损伤出发，比较全为1和全为2的阈值。另一节比较链、星形原阈值[1,1,2,1,1,1]及星形全为2；继发失效数为1/4/0，最大可用分量大小为4/1/1，比例用原六节点作分母。
- **练习 E1（选择题）**：区分直接与继发计数、失效触发与概率传播，说明连通路径存在不代表容量足够。
- **练习 E2（计算题）**：按旧累计失效集合同步触发，返回逐轮新名单；另搜索剩余最大分量并除以原节点数。
- **练习 E3（选择题）**：保持损伤和规则相同，分别改变结构或阈值；逐轮包含关系说明提高阈值不增加失效，但不保证指标严格改善。
- **核验与反馈**：四节点链、空损伤、高阈值及三种剩余比例与手算对应。级联计算保留已失效邻居的触发影响，评价可用图时才排除失效节点。
- **编写参考**：R13（资料与主题对应见本篇末表）。


### 13.3 扰动、恢复与早期预警

- **直接先修**：13.2、4.5、6.5；数学：数09、数17、数24、数43。
- **教学目标**：由同一扰动的方向比较局部恢复时间与吸引域，再按过去窗口和独立事件评价预警。
- **教学重难点**：有限扰动需要沿途的非线性信息；方差升高也可由噪声造成；事件检出与报警误报的计数对象不同。
- **内容顺序**：①同一1.4扰动的右端手算；②零点导数、正方向吸引域与Euler时间步；③一阶自回归的平稳方差和滞后；④过去窗口中心化、物理采样时长及报警计数。
- **核心实验**：恢复固定a=1.5/T，B取1与2，初值0.2与1.4，用0.02 T的25步比较至0.5 T。预警另用共享240个创新值；前120步rho=0.7、sigma=0.2，后段分别只改rho为0.95或sigma为0.5，窗口40项。两段均稳定，没有生成真实转变事件。
- **练习 E1（选择题）**：区分局部率与返回范围，检查数值交替、慢化条件、噪声对照和固定物理时差。
- **练习 E2（计算题）**：完整非线性Euler保留起点；窗口止于当前索引，方差除以窗口项数，相关片段各自中心化，无法定义时返回None。
- **练习 E3（选择题）**：用模型条件解释指标变化，保留恢复失败、无真实事件的方差上升和预警错误；综合计算题另按明确提前区间计数。
- **核验与反馈**：零点自身属于吸引域在非负半轴上的[0,B)，B不属于。越界后本模型没有另一有限稳态。追加未来值不影响当前指标；样本滞后乘采样间隔得到物理时差。检出和漏报数事件，误报数报警，函数返回计数。
- **编写参考**：R16（资料与主题对应见本篇末表）。


### 13.4 多尺度、粗粒化与不确定性

- **直接先修**：13.3、12.5、9.5；数学：数11、数17、数24。
- **教学目标**：手算同密度不同排列的未来，用配对频率补足一步平均，再区分条件差与尺度排序。
- **教学重难点**：距离两格的配对频率不是Pearson系数；精确一步密度尚未给出完整多步闭合；单因素差不是独立方差贡献。
- **内容顺序**：①两个四格环的逐格异或；②p与c2的精确一步聚合和独立近似；③共同参考的参数、观测和结构三项差；④粗细尺度评分、并列与敏感性范围。
- **核心实验**：四格1010与1100的p均为0.5、c2分别为0.5与0，下一步密度为0与1；均值场均预测0.5。另给共同参考0.50及单因素结果0.60/0.45/0.72，计算0.10/−0.05/0.22；粗尺度A/B为0.8/0.7，细尺度为0.4/0.6。代码展示给定表，未执行参数范围扫描。
- **练习 E1（选择题）**：判断平均可识别的数量与丢失的排列，说明c2补足一步但未给出下一步c2。
- **练习 E2（计算题）**：输入四格及以上的环形状态，返回p、c2和下一步密度；单因素题按同一参考返回三项有符号差。
- **练习 E3（选择题）**：解释粗细尺度排序反转、联合改变的相互影响和指定范围内的敏感性证据。
- **核验与反馈**：四格全部16种状态用直接异或核对聚合式。三项差保留单位及方向，严格反转要求两尺度方向非零且相反，并列不算严格反转。
- **编写参考**：R12、R13、R16（资料与主题对应见本篇末表）。


## 3. 篇末综合任务：临界变化、恢复与预警题组

固定群体模型、级联规则和稳态扰动场景。选择题区分有限规模证据、恢复速度、吸引域及预警解释；Python 题计算级联、过去窗口指标、误报漏报和多尺度差异；结果判读选择题包含无转变却触发预警和漏报。

覆盖 T1—T4；窗口与事件定义预先固定，题目检查未来信息边界；报警按[e−h,e)和(a,a+h]分别检查事件与报警，返回计数。各子题独立，不要求开放式韧性报告。

题组已交付，统一梯度、分值、等级及首次/练习成绩规则见[篇末分层评分](教材设计.md#capstone-assessment)。

| 层次 | 子题与分值 | 形式 | 主要计分目标 | 核验与反馈重点 |
|---|---|---|---|---|
| 1 基础辨析 | 1. 有限规模的临界证据（10 分） | 选择 | T1 | 辨认序参量、暂态与规模条件。 |
| 1 基础辨析 | 2. 恢复速度与吸引域（10 分） | 选择 | T3 | 区分局部恢复与大扰动后的去向。 |
| 2 方法应用 | 3. 逐轮级联失效（15 分） | Python | T2 | 固定初始损伤及更新规则，检查停止条件。 |
| 2 方法应用 | 4. 比较规模与重复结果（15 分） | Python | T1 | 对同一规模的重复轨迹先作时间内幅度平均，再作重复间汇总。 |
| 3 综合验证 | 5. 仅用过去窗口的预警（15 分） | Python | T3 | 窗口索引、缺失边界与未来信息泄漏检查。 |
| 3 综合验证 | 6. 分来源对照差异（15 分） | Python | T4 | 分别计算参数、观测与结构单因素差，不冒充方差分解。 |
| 4 迁移挑战 | 7. 更换事件条件后的误报漏报（10 分） | Python | T3 | 固定评估协议，保留无转变与漏报情形。 |
| 4 迁移挑战 | 8. 改变结构或尺度后的韧性（10 分） | 选择 | T4 | 结合级联、恢复与预警证据限定干预结论。 |

每题提供独立且完整的输入，不读取其他子题的作答；选择题提供逐项解释，计算题以公开契约、容差及独立参考判定。随机算法提供固定随机数、增量、索引或已生成结果，重复实验效果用于教材解释，不按一次随机效果判分。复习入口按本篇 T1—T4 对应章节建立，正式身份和版本随题库发布。

## 4. 教学资源与衔接

- **网页安排**：所有章都有独立页面、章内练习与篇末题组入口；以下仅说明可视化模块的取舍。13.1比较平均映射与两个规模的单次轨迹；13.2逐轮显示链或星形的失效和剩余分量；13.3将有限扰动轨迹与另一项AR(1)窗口方差对照并列。三页分别解释实际参数、轮次和单位；13.4使用Notebook的手算与柱图。
- **数据与案例**：沿用总纲 A（物质交换与清除）、B（稳态与节律）、C（个体与种群）三组生命系统案例；课程生成观测与核验状态/参数分离，同一方法比较使用相同观测、数据划分与预算。
- **独立验证**：逐章独立核验与反例见下列设计；随机实验对齐场景、重复次数和不确定性，不能用单次轨迹推断一般结论。
- **出口**：衔接第 14—17 篇的外推、鲁棒性与研究证据；不把预警指标或有限系统现象直接称为因果解释。
