## 五处代表改写

1. **有符号平均与一致程度。** 从两个方向相反、幅度同为0.8的群体开始，先说明为什么有符号平均会抵消，再定义绝对幅度。给出四个固定抽样值的一步更新，从单个±1变量推到群体平均的条件方差`4r(1−r)/N`，把有限规模波动接到实际随机规则。
2. **级联先看每轮新增。** 用链形网络逐轮记录初始损伤、继发失效和累计集合；公式明确排除已经失效的节点。再比较相同节点数、边数和损伤下的链与星形，逐笔计算剩余连通分量；连接规模作为代理，其大小不能直接说明容量是否满足需求。
3. **恢复速度与能否返回。** 两个模型保留相同零点线性恢复率，吸引域边界分别为1和2。从1.4出发，第一步导数分别为0.84和−0.63，Euler更新为1.4168和1.3874。有限扰动能否返回取决于沿途规则，局部恢复率相同也不表示有限扰动轨迹完全相同。
4. **预警先明确时间和计数。** 从四点窗口`[0,1,2,3]`的方差1.25和滞后相关1开始，说明窗口含当前值、配对片段各自中心化及未来值不得参与。AR(1)推导区分恢复变慢与噪声增大；报警例明确检出与漏报数事件、误报数报警，三个计数尚未换算成率。
5. **同一平均不能保留局部结构。** 将四格环`[1,0,1,0]`和`[1,1,0,0]`逐格更新，说明相同密度0.5为何得到下一步密度0和1。再推导`p⁺=2p−2c2`，区分精确一步密度与多步闭合；分来源对照使用共同参考，联合改变的手算例说明单因素差不能默认相加。
