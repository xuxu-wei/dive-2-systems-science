# 外围单色碎片与中央留白 · 2026-09-23

**本轮视觉调整与操作检查完成；此前的完整换肤性能验收仍保持开放。** 用户指出密集、多色反光显得杂乱，本轮收敛为外围彩色碎片、向内淡出、单片慢变色与少量中央白色荧光。

## 已实现

- 彩色碎片最多 20 片，分散在四边；实际位置越靠中央越透明，进入中央区域后消失，返回外围渐显。动画关键帧使用实际窗口尺寸计算，调整尺寸时保持播放时间，不重新从零开始。
- 同一片面只有一种基本色相和原有明暗纹理，沿蓝↔青、粉↔紫、青↔深蓝缓变；移除空间彩虹、反光条带和白色反射峰。中央白色荧光减为 16 点、4 组。
- 复用原背景图；鼠标仅在靠近边缘时带来最多水平 4 px、垂直 3 px、0.075° 的微弱偏移，返回中央或离开后复位，不增加亮斑或碎片形状。暂停保持，减少动效恢复静态。
- 规则与参数只维护于[网页规范](../网页设计规范.md#site-appearance)。本轮未改课程图谱、五论、内容、题目/Notebook 身份、后端或个人记录。

## 实际验证

环境：Windows、Codex 内置浏览器，`http://127.0.0.1:8000/`，前台 visible；检查默认 1219×1272、浅色 1280×800 和深色 1920×1080。短窗口沿用纵向滚动，无横向溢出。

| 检查 | 结果与证据 |
|---|---|
| 画面留白 | 默认及宽屏中彩色片位于边缘，中央天体和标签清楚；1920×1080 实测中央可见彩色片为 0。空间淡出另覆盖多尺寸和完整循环的自动检查。 |
| 慢变色与漂浮 | 2.4 秒采样中，8 个当时可见片面的变换/透明度、8 个整片色层透明度、4 组白色星点发生变化。[数据](quiet-edges-20260923/motion-and-edge-hover.json)。 |
| 单片单色 | 抽取 12 张实际运行材质的不透明像素，单张色相范围 1.16°—3.53°，为灰阶着色与字节量化的微小差异，没有原先的多色条带。[材质像素检查](quiet-edges-20260923/single-hue-materials.json)。 |
| 背景鼠标响应 | 真实鼠标移至右侧，测得约 x=−3.75 px、y=−1.45 px、转角约 0.07°；移回中央后变换回到单位矩阵。 |
| 暂停与减少动态效果 | 点击暂停后全部环境动画 paused；模拟减少动态效果后全部 paused 且 currentTime=0，背景变换为 none；检查后撤销模拟。[暂停](quiet-edges-20260923/pause.json)、[减少动效](quiet-edges-20260923/reduced-motion.json)。 |
| 主题与兼容绘制 | 实际切换深浅；触发 WebGL 上下文丢失后自动改用 Canvas，边缘效果保留，双击进入第 1 篇正常；最终刷新恢复 WebGL、深色及默认窗口。 |
| 自动与保护 | 79 项 JavaScript 检查通过，包含向内淡出、循环连续、调整尺寸不重置动画、背景响应边界与原导航/进度等回归。29 份个人 JSON 哈希相同，AGENTS.md 无差异。[记录](quiet-edges-20260923/verification.json)。 |
