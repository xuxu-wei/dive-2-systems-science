## 五处代表改写

1. **局部更新先给可读的记录。** 原文仅要求“手算四格周期环”。现在先说明1表示激活、列表按从左到右排列、下标从0开始，再用表列出每格左右旧值。下一节继续手算同一初态的同步、从左到右异步和反向异步，得到`[0,1,0,1]`、`[0,0,0,0]`、`[1,0,1,1]`，让读取时刻的区别具体可见。
2. **收益表接到频率导数。** 原文直接列出复制动态。现在先说明行是自身、列是对方，再以p=0.25分别得到两类收益率0.75/T、1.75/T和群体平均1.5/T。从两类数量增长、总量变化和比例求导，推到`dp/dt=p(1−p)(f0−f1)`，解释为何本类数量增长时，占比仍可能下降。
3. **随机概率与实际计数分开。** 选择变异例先得到选择后和变异后概率2/3，再用四个给定抽样值得到实际频率1/2。轨迹图明确使用80条独立实现，阴影是10%—90%经验分位范围，区分群体间分散和平均值置信区间。
4. **无通量写成端点如何交换。** 网页原称“反射端点”。现在说明数值记录在格子中心，端点只与系统内相邻的一格交换，越界值取端格旧值；左端更新是`c0+=α(c1−c0)`。同时保留总和为2却得到`[2,-2,2]`的大步长反例，说明守恒不足以核对非负性。
5. **精确一步关系与闭合分开。** 原题提示称保留c2是“精确闭合”。现在明确c2统计中心格左右两格同时为1的比例，推导`p⁺=2p−2c2`；它能精确给出下一步密度，但尚未给出c2自身的更新式。块平均还用相同`[0.5,0.5]`却得到不同下一步密度的例子说明信息损失。
