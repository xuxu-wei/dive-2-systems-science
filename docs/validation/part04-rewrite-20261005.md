## 表达调整

阅读 [D2L 微积分](https://zh.d2l.ai/chapter_preliminaries/calculus.html)中由变化、差商进入规则与具体计算的段落，以及 [Python Causality Handbook 导论](https://matheusfacure.github.io/python-causality-handbook/01-Introduction-To-Causality.html)中由具体比较与反例进入形式记号的段落。借鉴引入和解释顺序，未复制原文，也不将阅读选段写成完整学习两本书。

| 原有阅读障碍 | 本轮处理 |
|---|---|
| 集合吸引一节集中列出紧、不变、距离下确界 | 先求一个点到单位圆的距离，再说明向前不变、完整不变与集合稳定；用两条轨迹的相位差解释趋近圆周的含义 |
| 分岔公式与扫描摘要之间缺少推理 | 联立平衡与零斜率，展开折叠点附近的变化率；把解析阈值、接续初值、等待时间和有限跳变区间连接起来 |
| 离散增长率直接给出对数均值 | 从逐代手算和局部倍率乘积进入对数和，说明第 0 代、零导数、阈值与窗口，再用特殊初值和高精度对照解释结果 |
| Lorenz 部分连用迹、截面、插值与变分方程 | 把迹解释成雅可比矩阵对角线之和；手算交点比例及 `[时间,x,y,z]` 顺序；由相邻状态相减推导小扰动方程，按真实累计时长求增长率 |
| 网页只显示未命名的数对或三元组 | 分别显示第一条与邻近轨迹，或具名 `x`、`y`、`z`；把“只改变精度”改为“只改变步长”，说明各图对应的比较对象 |

保留数学桥接、原有推导和科学条件；前文已建立的术语直接承接，本篇新术语按首次使用检查。必要条件放在具体推理中。普通课节高精度图的说明按原代码修正为 50 位、80 次；综合原有 40 位、35 次对照单独说明。习题中“固定积分步数”的定积分误注改为中点更新次数，运算精度与打印精度的解析混淆也已修正。
