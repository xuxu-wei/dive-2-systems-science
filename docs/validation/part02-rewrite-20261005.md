## 具体改写

| 原有表达或解释缺口 | 本轮处理 |
|---|---|
| 2.1.1 开篇说“两条规则都变少”，但空池补入后实际增加 | 用 `10→8→6.4` 与 `0→1→1.5` 的手算比较，说明两者都有损失，补入仍可使总量增加，再建立递推与固定点。 |
| 速率、时长、段末列表的来源不够直观 | 先写明两段条件，手算 `1→1.75→0.875`，再对应速率 `[2,0]`、时长 `[0.5,1]`、三项总量及累计清除 1.125 U。 |
| 差商、矩形求和与微积分符号各自罗列 | 从两个时刻的总量差除以时长进入左右极限；从四个短段流入量进入定积分；解释遍历变量与累计终点，再用初值恢复总量。 |
| 数学桥接与数值解释分开，容易跳到结论 | 保留指数、对数、链式法则、分离变量与小系数稳定表达；从指数二次展开及余项上界进入局部误差，再展开误差传播，说明固定终点下的全程一阶误差。 |
| “边界”“同一位置”“第 i 个时段”所指不清 | 写成分段时刻，区分观察起终点与输入切换点；区别分段索引与计算步索引，说明 `residuals[i]` 检查 `amounts[i]→amounts[i+1]`；半步比例作用于该半步起点。 |
| 综合说明停留在“等总量不等过程” | 完整列出三种方案，分别解释峰值、峰值时刻、终值及累计清除，再加入全程上限逐项判断。零清除题面区分线性积累与正系数下趋平衡。 |
