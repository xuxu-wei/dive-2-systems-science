11份讲授源稿位于`lessons/15-可微分建模与机制融合/`，共75个带稳定锚点的H2段落（含参考资料）。48题各关联一个具体概念，五处概念链接通往五张实际探索；正文解释12张实验图。当前迁移范围为导论及第1—15篇182节网页，第16—17篇保留完整Notebook教学。

网络输入先由物理量除以参考量，响应参数与损失保留对应单位；训练另明确参考单位下的数值坐标。四参数梯度按w/b/v/c排列，共享误差两条路径相加；自动微分所求的是实际程序的目标导数。15.1.2同一绘图单元的两张图分别解释差分步长扫描和400轮响应拟合。已知目标在范围外x=1.5处的1.260874与原预测1.357319另作手算比较，不新增训练。

离散映射明确1 T采样间隔、输入量而非输入率、N次更新的N+1个状态。真实当前状态的一步预测返回N项，自由路径含初态。固定特征的三系数最小二乘在无噪声例中恢复[0.85,0.2,0.06]；失配候选在留出轨迹上的一步与滚动MSE约为0.000980和0.028982 U²。省去tanh后，训练一步/滚动目标选择0.917/0.9175，新初值的MSE排序由实际比较给出。

连续灵敏度先以固定初态和时刻推导，再与Euler程序导数分别核对。连续伴随在最后观测之后为零，反向跨过每次观测加入残差；参数积分按正向时间写出。多状态形式明确Jacobian尺寸和转置；离散伴随使用保存的前向状态。两张细化图改为分面，各自显示状态/灵敏度或梯度/重建误差的单位，并用实际步长作刻度，原计算与参数保持。

物理约束两节分别评价给定候选，没有执行PINN训练。方程、初值和边界采用各自残差尺度；归一化位置下扩散系数单位为1/T。21个时空点逐项配对，41个参考位置同时用于页面方程与参考检查；空间线性项同时改变初始剖面与端点条件。页面参考RMSE由同一网格计算，另有数值回归核对。

混合tanh修正幅度为U/T，线性修正系数则为1/T。前者固定机制参数学习一个幅度，再比较新输入；后者只有k−θ进入总量方程，非零状态处独立机制通量kx才能额外区分k。预设候选权重先归一化，预测方差按给定候选计算；不写成后验权重。课程演示与第17篇的原论文条件及复现任务分别组织。

题库、解析、选项顺序、版本、函数签名、输入输出结构、样例、判定和评分源保持。篇末综合八题100分，首次作答分与练习达成分分别显示。
