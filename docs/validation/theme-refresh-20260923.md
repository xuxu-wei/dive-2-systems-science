# 全站低模主题与交互反馈验收

2026-09-23；用户批准后实施。范围是替换旧 dark、优化 light 和共享反馈，课程、题库、评分协议不变。当前规范见[网页设计规范](../网页设计规范.md#site-appearance)；视觉对照见[设计 QA](../../design-qa.md)。

## 实际交付

- 两套本地低模背景与透明六格几何片图集；首页共享装饰画布提供异步呼吸、缓慢漂移、星点与轻视差。目录、导览、练习、可视化只用静态底纹。
- 深浅界面使用统一颜色与控件状态；悬停、按压、焦点、选中、内容切换、原生折叠展开和结果出现有短反馈。保留科学图表、五论、Monokai 与进度/错误语义。
- 主题状态同步更新，注册颜色属性及背景层在 250 ms 内渐变，直接命中现有控件。原生整页快照方案曾吞掉紧接着的点击，已移除；复验“切主题后立即点帮助”通过。
- 首页暂停同时冻结天体与环境；后台不累计时间，减少动效关闭自动开场和装饰运动。持续慢帧减少装饰，不影响课程状态。
- 放大文字时增加星图纵向空间、篇号不换行；保持正常字号构图和 850/700 ms 层级时长。
