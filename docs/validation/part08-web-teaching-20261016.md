## 单独登记的既有题面问题

`p08-conditioning`选项B写“误差不发散，步长必须严格小于……上界”，解析实际要求“严格衰减”。在η=2/λmax时，最大曲率方向的误差等幅交替且有界；严格小于上界保证任意初值误差趋零。正文已准确区分。此项需要后续单独将题面限定为“误差逐步趋于零”并评估成绩兼容，本轮保持题目及答案原状，未混入迁移改题。
