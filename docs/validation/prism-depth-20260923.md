# 分层玻璃碎片与漂浮星点 · 2026-09-23

**状态：本轮视觉与交互检查完成；连续换肤流畅度仍未通过。** 本轮在既有未提交工作上扩展环境动效，未改天体形态、五论分类、教学内容、题库或学习记录。

## 实现与范围

- 由最多 12 片扩展为最多 32 片，四档径向尺度由中心小片过渡到外围大片；按实际星图区放置，短窗口不会让大部分碎片藏在标题/卡片后。
- 天体下方后景 z=0，天体 z=1，前景 z=3，节点文字/命中层 z=4，控件更高；装饰统一 `pointer-events:none`。黑洞视界与文字避让，行星表面允许小片从前方经过。
- 基础材质带青/紫/粉渐变，较大碎片额外预生成反光层；缓慢旋转、倾转、漂移与明暗循环。复用既有透明 PNG，不新增图像依赖或独立 WebGL 场景。
- 白色荧光星点共 24 个、6 组，分布于前后景；隐藏的碎片和星点组暂停动画，减少无效合成。全局暂停、后台和减少动态效果继续统一生效。当前参数只维护在[网页规范](../网页设计规范.md#site-appearance)。

## 性能结果与未验收项

- 最终 1920×1080、WebGL 前台空闲采样约 2.5 秒：帧间隔 P95 33.3 ms、最大 39.5 ms，未观察到 >50 ms 的主线程长任务。[原始结果](prism-depth-20260923/idle-webgl-final.json)。这与常态 30 fps 预算一致，但不能用短采样证明整体流畅。
- 本轮迭代中在默认窗口连续换肤，最大帧间隔分别出现 361.1 ms 和 229.3 ms，长任务包括 140 ms、51 ms。指南仍可立即操作，但**不能把换肤卡顿标为已消除**。[实际结果](prism-depth-20260923/theme-switches-and-pause.json)。最后的星图区分布调整未改变换肤逻辑。
- 首次同步等待式 CDP 性能采样超时，后改为非阻塞短采样；页面继续可操作。原始 CPU 采样保存在忽略目录 `.local/prism-depth-profiling/`，不纳入教材同步。
- 本轮未重复全站页面、200% 字号、全部侧栏宽度及所有屏幕尺寸的完整性能矩阵；此前报告的完整跨页性能验收仍开放。
