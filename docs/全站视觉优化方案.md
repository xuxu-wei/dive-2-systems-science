# 全站深浅主题视觉优化方案

2026-09-23；状态：用户批准后已实施。当前规则归[网页规范](网页设计规范.md#site-appearance)，实际检查与限制见[验收记录](validation/theme-refresh-20260923.md)；下文保留批准时的设计依据与初始预算。

## 1. 已确定的范围与依据

用户选择最近一组三张预览中的第 3 张，并补充蓝紫、青蓝低模折面参考。新方案直接替换旧深色主题，同时优化浅色主题；**全站仍只有 dark / light 两个主题**，撤销此前新增第三主题的提议。

- [已选视觉目标](design-reference/low-poly-selected.png)：主要采用稀疏几何片、低亮度渐变、中心留白与轻盈氛围。
- [新增配色参考](design-reference/low-poly-palette-reference.png)：补充冷蓝紫、青蓝与暗部折面关系。图片很小，参考色彩关系，不据此宣称精确材质或原图色值。
- 用户随后提供手机拍摄视频 `微信视频2026-09-23_025747_426.mp4`（约 5.34 秒）。已抽取连续画面检查：深色大折面位于后方，半透明小三角片和稀疏光点在前方改变位置与亮度。以此补充材质层次和漂移方式；拍摄模糊、偏色、曝光变化、屏幕纹理与镜头抖动不作为设计效果。原视频和分析帧不作为网页资产，也不纳入仓库。
- 预览图中的文字、重复控件、节点数量和分类颜色均不作为实现数据。布局以现有网页规范和真实课程数据为准。

保留导论黑洞、17 篇及篇—章—概念层级、左右卡片循环、单击/Tab 选择、双击/Enter/滚轮进入、末级明确请求 IDE 等交互。此次优化不改变教材、题库、评分、个人记录或后端协议；AGENTS.md 保持不变。

## 2. 视觉方向与颜色

整体采用「低模几何背景 + 宇宙知识星图 + 清楚的教学界面」。三角形和菱形主要位于外围与空白区域，中央留给天体、关联与学习信息。后方的大折面提供低模体积，前方的小片提供轻盈层次；镜面感来自相邻面的微小明暗差和少量边缘反光，不增加巨大碎镜、晶体山体或反射地面。

以下为实施起始色值，允许依据真实渲染对比度微调明度；背景/控件色不替代五论、进度或科学数据色。

| 用途 | 新深色 | 优化后的浅色 |
|---|---|---|
| 页面底色 | `#0B1024` | `#F5F7FC` |
| 卡片与题面 | `#12182E` | `#FFFFFF` |
| 抬高表面/输入区 | `#1A2240` | `#EDF0F8` |
| 正文 | `#EDF0FA` | `#202742` |
| 辅助文字 | `#B7C2DB` | `#5E6880` |
| 主按钮 | `#D7DCF1`，字 `#18203A` | `#414C7E`，字 `#FFFFFF` |
| 主按钮悬停 | `#E8EBFA` | `#505D96` |
| 链接 | `#D0D9F2` | `#414F86` |
| 选中表面 | `#283253` | `#E4E9F7` |
| 键盘焦点 | `#85CDD4` | `#465CC2` |

环境基色保留用户指定的 `#232566` 与 `#4A4A7B`；`#7B1F3D` 用于极少量暗部折面，`#FF6BA1` 用于少量几何片与局部交互强调。参考图的青蓝反光建议以 `#6FC9D0` 为初始值，蓝紫反光以 `#6884CD` 为初始值；均是提案色值，不声称逐像素取自参考图。主界面不重新使用 `#91B8ED`。

浅色把相同蓝紫/青蓝关系转换成低饱和度的光影与淡色折面，减少发光，强调实线边界和轻柔阴影；不对深色页面直接反色。黑洞维持清楚暗核和暖色吸积盘，背景装饰不侵入其轮廓。

纯色组合初算：深色正文/卡片约 15.42:1，深色辅助文字/抬高表面约 8.73:1，深色主按钮约 11.78:1；浅色正文/白卡约 14.68:1，辅助文字/抬高表面约 4.89:1，主按钮约 8.20:1。透明叠加、焦点、禁用和过渡帧仍须在实际页面检查。

五论保持现有两套色板、分类与线性混色规则，图例和 WebGL/Canvas 同步；未开始灰、进行中橙、完成浅蓝、答错红的语义不变。Pink 主题装饰不表示错误；答题结果同时有文字和图标。Monokai 编辑器、traceback、科学曲线和 Notebook 图表沿用现有定义。

## 3. 背景、天体与光影

| 层次 | 深色表现 | 浅色表现 |
|---|---|---|
| 基底 | 连续深靛蓝渐变、极淡低模明暗 | 冷白渐变、淡蓝紫纸面光影 |
| 远景 | 稀疏暗星，少量亮星，轻微异步亮度变化 | 很少的微光点，避免白底脏点 |
| 几何片 | 约 12—24 片，12—65 px，透明度约 3%—14% | 相同构成，透明度约 2%—7% |
| 大尺度折面 | 仅边角少量近乎不可见的折面 | 极浅分区明暗，无明显拼贴边界 |
| 主星图 | 保留黑洞/星系/星球层级、分类色和成就光辉 | 保留形态，以色相、深色轮廓和局部阴影辨识 |

数量以 1440 px 级 PC 视图为初始预算，随实际可用区域减少，不因超宽屏无限增加。几何片使用确定的布局种子，调整侧栏或窗口时连续移动，不全部重生。位置避开卡片、标签、图例、工具栏与节点命中区；装饰不可点击且不拦截指针。

小几何片独立以 **6—14 秒**呼吸，初相位错开；透明度平滑升降。结合视频中的漂移感，部分小片再以 **12—24 秒**周期缓慢位移约 **8—24 px**，少量旋转 1—3°，其余保持更稳定的位置。暗色大折面基本固定，仅有极弱光照变化；不把所有面片一起平移或同步缩放。上述参数是实施起点，5.34 秒手机片段不足以测定原动画完整周期。

近处三角片边缘清楚、表面有柔和明暗，远处少量片可轻微虚化；禁止以全屏模糊模拟质感，也不复制参考视频中明亮矩形区域的外边界。清晰度与对比度须在原生 PC 分辨率检查。中心视界不呼吸缩放；吸积盘光流、星系自转与公转应仍能在数秒观察中辨认。

鼠标视差最多约 2/4/6 px 分别作用于远、中、近背景层，不移动文字或真正的节点点击区域。拖拽、滚轮切层时不叠加额外视差；停止操作后平滑恢复，避免镜头与背景各自漂移。

## 4. 控件反馈与主题响应

用共享动效参数覆盖默认、悬停、按压、键盘焦点、选中、加载、禁用及成功/失败状态；不只给首页增加特殊效果。

| 操作 | 视觉反馈 | 初始时长 |
|---|---|---|
| 普通按钮悬停 | 背景/边界提亮，少量阴影；最多上移 1 px | 140—180 ms |
| 鼠标按下 | 轻微压低；短按钮最多缩至 0.98，宽按钮只改变表面 | 70—100 ms |
| 松开/移出 | 从当前状态恢复，无弹跳和反复过冲 | 160—220 ms |
| 键盘焦点 | 清楚的 2—3 px 外轮廓，出现即能辨认 | 立即，颜色过渡最多 100 ms |
| 标签/目录选择 | 选中底色及短指示线平滑更新，文字不跳动 | 180—220 ms |
| 卡片左右切换 | 内容交叉淡化，最多 4 px 定向位移；节点同步选中 | 180—240 ms |
| 目录展开与帮助 | 轻微高度/透明度过渡，结束后无空白占位 | 160—220 ms |
| 主题切换 | 整体画面短交叉渐变，文字与所在表面同步 | 220—280 ms |
| 判题反馈出现 | 代码区上方就近呈现，轻微淡入，无庆祝粒子 | 140—180 ms |
| 层级进入/返回 | 保留已有连续镜头及材质衔接 | 850 / 700 ms |

普通缓动沿用自然减速曲线 `cubic-bezier(.2,.75,.25,1)`；按压反馈更快。所有动画可从当前状态中断并反向，快速移入移出、连续切换不会排队补播。不可用按钮保持可读但不抬升、不闪亮；等待 IDE 或判题响应时显示实际处理中状态，响应后才给成功/失败反馈。

卡片换内容期间保留键盘焦点和可访问名称；连续循环不丢点击。目录宽度拖动直接跟随鼠标，不加缓动滞后。习题选项以边界和选中状态反馈，不移动题干或改变点击目标。

主题偏好仍为 `systems-science:theme:v1` 的 dark/light。旧 dark 自动获得新视觉，无第三主题、无偏好迁移。首次加载先恢复主题再绘制；跨页/刷新不闪回另一主题。主题切换不重建题目、编辑器或模拟状态，不重播开场，不重置镜头。五论图例与节点使用同一帧的分类色；连续切换以后一次选择为准。浏览器不支持过渡时立即切换，功能不受影响。

## 5. 全站使用强度与阅读体验

| 页面 | 氛围 | 控件与阅读要求 |
|---|---|---|
| 首页三层星图与导论 | 完整背景呼吸、轻视差和天体运动 | 保留现有居中构图、固定信息层和可用星图区 |
| 全书/篇/章目录 | 同风格的淡静态几何底纹 | 卡片编号、学习进度和整卡入口清楚；不持续闪动 |
| 章节导览 | 页边少量静态折面，正文表面稳定 | 重点、知识体系和 Notebook 入口优先 |
| 练习 | 页面边缘极淡底纹，题面和代码区不覆盖装饰 | 保留宽工作区、软换行、缩进、高亮和上方结果反馈 |
| 可视化/探索 | 外围面板跟随主题，实验画布保持科学颜色 | 区分环境动效与教学播放；主题切换不推进仿真 |

正文建议 17—18 px，目录与按钮 15—16 px，星图节点名称至少 14 px，次级标签不低于 13 px。提高行高与段落间距，长标题换行适应卡片；不为装入一行而缩小文字。圆角、边线和阴影建立少量统一等级，不把所有内容都套成高亮玻璃卡。

PC 检查 1280×800、1440×900、1920×1080、2226×1185；覆盖侧栏隐藏、展开、调宽及文字放大。较短窗口沿用可纵向滚动规则；页面没有横向溢出、标签遮挡或大块无用途占位。不做手机专项适配。

## 6. 动效控制、性能与失败处理

首页现有暂停统一冻结背景呼吸、天体运动和环境光流；悬停/键盘聚焦节点仍按现有规则冻结相关场景时钟，移开后连续恢复。其他页面默认静态背景，无需增加一排装饰设置。用户主动触发的切层和按钮反馈保持可用。

系统减少动态效果时关闭自动开场、视差、持续呼吸与位移，采用静态背景和即时状态变化。切到后台暂停环境更新，回来不累计时间突跳；教学动画仍遵守主动播放、独立暂停规则。

优先复用现有本地渲染和共享样式，不新增大型动画框架，不为背景单独创建一套 WebGL 场景。以 30 fps 为环境动画初始预算；仅动画透明度/变换或使用已有绘制时钟，避免每片各自读取布局。控制像素比与素材尺寸，不在每帧生成噪声纹理、重排导航或渲染题目。

性能下降先减装饰密度和反射细节，再关闭装饰运动；保留天体、标签与交互。WebGL/Canvas 共用颜色和几何布局来源，回退可简化光照。资源未加载、上下文丢失或暂停恢复异常不得导致按钮无反应；无法绘图时保留可读的目录入口。

## 7. 实施顺序与验收交付

1. **视觉基线**：以已选第 3 张和新色彩参考定稿成对的深浅首页及控件状态；建立配色、边界、字号、阴影和动效参数。沿用原布局，修正预览图中的非真实内容。
2. **共享界面**：先改 `web/shared/appearance.css` 与公共控件样式，把新皮肤同步到目录、导览、练习、探索；保留 `boot.js` / `appearance.mjs` 的两主题协议，处理主题切换动画。
3. **首页环境**：再调整 `web/home/style.css`、渲染器与时钟，加入低模片、星点纵深及深浅材质，绑定暂停/减少动效。必要的装饰帮助模块应轻量且不持有课程状态。
4. **交互打磨**：统一按钮、卡片、菜单、选择题、目录和结果弹层的全部状态，处理快速点击、焦点及中断；保留 0.5—1 秒切层时长。
5. **实际验收**：两主题 × 四类主要页面 × 常用 PC 尺寸，检查全部控件状态、透明叠加对比、五论远近景/混色、暂停/恢复、快速切换和 WebGL 回退。检查 200% 文字缩放及键盘操作。
6. **验证与文档**：记录机器、浏览器、渲染路径及实际帧率/交互响应，保存同视图深浅对照截图和动效证据；通过相关自动检查，确认个人记录及教学计算不变。将最终规则并入网页规范、制作检查表；ROADMAP 简报不超过 20 行，README 仅在实际能力变化时更新。

完成条件：新 dark 已替换旧视觉、light 同风格且可读、全站主题一致、背景低调且无拼接方块、控件响应即时且不会积压动画、分类与成绩语义准确。静态预览、设计参数和目标帧率均不能单独作为完成证据。

## 8. 实施取舍

- 浏览器整页快照过渡在实际 PC 点击中会暂时吞掉操作，首轮改为注册颜色属性与两层背景渐变；用户随后指出卡顿，现已取消继承颜色动画，改为界面色同步更新、仅背景透明度渐变，输入保持可用。
- 大折面固定；动态集中在小几何片、星点与现有天体。采用按下表面变暗与回位，不对宽按钮缩放。
- 目录与提示保留原生折叠，展开内容短淡入，不动画关闭高度；减少隐藏内容残留和焦点跳动。
- 字号放大时额外增加星图纵向空间，保留原有正常字号构图。没有新增依赖、后端或学习记录格式。

## 9. 用户反馈后的修正（2026-09-23）

首轮几何片的透明度和位移过小，慢帧降级还会把时间永久固定为零。上述第 3 节参数仅保留为初始设计记录；当前参数及规则统一维护于[网页规范](网页设计规范.md#site-appearance)。首轮修正为 12 个合成动画；随后按用户要求增加径向大小、前后景、镀膜反光和白色漂浮星点，当前密度与控制统一见网页规范。静态星点仍缓存，暂停与减少动效统一控制。

用户指出的白色椭圆来自导论按钮的选中伪元素，已移至标签强调。同步移除动态背景上的大面积模糊、整页继承色过渡、长正文入场动画与每帧节点布局；更新图例和节点数据时保留已有结构。

最终前台流畅度尚未完成复验；过程中仍观察到长帧，不能把首轮“通过”或这次优化措施视为卡顿已经消除。实际范围见[修正记录](validation/theme-motion-fix-20260923.md)。


后续碎片扩展未新增主题或独立 WebGL 场景；复用透明图集预生成反光材质，只有较大碎片叠加动态反光层。分层、短窗口密度与实际采样见[环境动效检查](validation/prism-depth-20260923.md)，性能未通过项仍单独跟踪。


用户随后指出画面过杂：当前收敛为外围碎片、向内淡出、单片单色缓变；中央只留少量白色荧光，原有背景折面加入微弱边缘鼠标响应。上述密集径向碎片和镀膜条带保留为迭代历史，当前规则以[网页规范](网页设计规范.md#site-appearance)为准，实际复验见[环境收敛记录](validation/quiet-edges-20260923.md)。
