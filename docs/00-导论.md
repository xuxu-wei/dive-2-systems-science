# 导论：走进系统科学

导论位于第一篇之前，采用三个独立 Notebook，回答系统科学研究什么、为什么有用、方法怎样发展，以及如何开始学习。它与正文的 17 篇、85 章分开统计，对应 [M19](../ROADMAP.md#milestone-m19)。共同的术语、题型和教学要求见[教材设计](教材设计.md)，这里仅维护本单元的具体设计。

## 四个可检查目标

| 目标 | 学习成果 | 检查依据 |
|---|---|---|
| D1 | 在新情境中识别组成、相互作用、环境与整体行为之间的问题 | 生命现象辨析、传播连接对照 |
| D2 | 区分演化、认识、调控及验证应用等研究任务 | 为具体问题选择所需证据与方法 |
| D3 | 辨认主要学术传统回应的问题及相互补充的关系 | 历史问题匹配；不考人物、年份记忆 |
| D4 | 从简单实验得出有依据的结论，定位后续学习内容 | 手工枚举、结论范围与全书学习地图 |

## 导览信息

### 0.1 走进系统科学

- **教学目标**：从生命现象识别相互作用与整体行为；区分演化、认识和干预问题；理解主要学术传统的联系；用简单实验核对结论并定位后续学习。
- **直接先修**：入口。阅读只需日常经验和中学计数；重现第三节代码使用 Python 列表、循环和函数，绘图代码随节说明。
- **教学重难点**：把研究对象、相互关系与研究问题连起来；理解整体研究与局部机制研究相互支持；区分给定规则的实验结果与对真实对象的解释。
- **内容顺序**：① 从运动后恢复、物质积累与个体传播认识系统；② 以五类问题理解学科全景，并串起相互交汇的发展脉络；③ 比较六个个体的消息传播，连接计算、证据、应用与全书学习路线。
- **数学桥接**：只用计数、列表和轮次。模型的正式变量、收支、递推和网络表示分别在第 1、2、11 篇完整建立；本单元不提前建立这些章节的数学先修。
- **实验**：链形 A—B—C—D—E—F 与星形 A—{B,C,D,E,F}，均为六个个体、五条双向联系。初始只有 A 收到消息；每轮仅由上一轮已接收者传递，接收后保持。手算前三轮，再运行显式循环；改变起点观察同一连接方式下的差异。
- **核验与反馈**：链形从第 0 至 5 轮人数为 [1,2,3,4,5,6]，星形为 [1,6,6,6,6,6]；检查零轮、无连接、六种起点、边的枚举顺序和同步更新。选择题均有逐项解析，题面与 Notebook 由同一题库同步。
- **练习设计**：三节各三道选择题，覆盖 D1—D4；导论单独显示自测通过数，不建立篇末百分制综合或学习门槛。现有章内题及综合评分保持原义。

## 三个小节

| 小节 | 目标与内容 | 图示、活动与练习 |
|---|---|---|
| 导论·1 从生命现象认识系统 | D1、D2。以运动后热量产生、运输与散失的关系为线索，解释系统、系统科学、环境和整体行为。用物质积累与个体传播迁移视角，说明局部机制与整体关系相互支持。 | 案例关系图；先用文字判断需要观察哪些关系，再辨认系统问题。三题为恢复研究、相同个体的不同连接、研究目的与证据。 |
| 导论·2 系统科学关心什么，如何发展 | D2、D3。以提出问题、演化、认识、调控和实践五类问题定位方法。穿插一般系统论、控制论、信息论、非线性动力学与混沌、复杂系统与网络、数据与机制融合；介绍钱学森及中国系统科学发展的相关脉络。 | 多线交汇的发展示意图，节点表示代表性工作而非学科唯一诞生时刻，连线表示问题之间的联系。三题为传统与问题、五类视角的配合、学科间互补关系。 |
| 导论·3 从系统问题走向计算与证据 | D1、D4。手算和显式实现同步传播；比较相同人数与联系数下的传播路径；解释模型假设、实验结论及下一项所需证据。将方法用于生命、工程与生态问题，并定位全书学习路线。 | 连接图与逐轮人数图；对照 A、F 等不同起点。三题为独立输入下的传播计数、结论范围、学习地图定位。 |

## 九道自测的覆盖

| 题号 | 题目 | 目标 | 客观判定依据 |
|---|---|---|---|
| p00-recovery | 从恢复现象提出系统问题 | D1、D2 | 同时研究组成、联系、环境和随时间变化的结果 |
| p00-connections | 相同个体能否产生不同整体行为 | D1 | 连接变化可以改变传递路径，个体数不能唯一决定结果 |
| p00-purpose | 先分清要回答的问题 | D2 | 预测演化、从读数认识内部情况、选择干预分别需要对应任务 |
| p00-traditions | 思想怎样回应问题 | D3 | 一般系统论、控制论、信息论、非线性动力学的研究侧重 |
| p00-perspectives | 五类视角怎样配合 | D2、D3 | 同一问题可以同时需要认识、调控与实践核验 |
| p00-complement | 新方法与既有知识 | D3 | 数据、机制、局部研究和整体研究互相补充；分类不是唯一标准 |
| p00-rounds | 独立判断前三轮 | D1、D4 | 按题面给定的六人链和 A 起点逐轮枚举 |
| p00-evidence | 实验支持多大的结论 | D4 | 结论受连接、规则与起点约束；推广需要额外机制和观测 |
| p00-route | 找到后续学习位置 | D4 | 使用题面提供的学习地图，定位状态估计主题与顺序学习起点 |

每题有独立完整输入。自测用基础辨析、联系理解、计算读图和迁移辨析逐步推进，不要求提交自由文本或 Python 代码。

## 正文衔接与网页

推荐路线为导论·1—3 → 1.1 → 原有篇章顺序。1.1 承接研究问题并正式建立边界、状态与观测；1.4 回看导论中的同步规则、起点与证据。导论预览过的概念仍在原章节完整解释，不调整数学索引和先修图。

目录采用独立 `introduction`，内部 `0.1` 与 `P00-C01-S01`—`S03` 仅用于稳定标识。读者看到“导论”和“导论·1—3”。导览、自测和探索分别位于 `/introduction/`、`/introduction/practice/`、`/introduction/explore/`。交互实验提供连接选择、起点、单步、播放、暂停与重置，图与人数表使用同一轮次。首页和目录提供先读入口；导论的自测不并入任何篇的成绩或星图进度。
