# 学习指南

## 安装与启动

准备 Python 3.11 或以上版本。在项目根目录打开终端，执行：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e ".[learn]"
```

安装完成后双击根目录的 `开始学习.cmd`。它会检查并启动本机教材服务，打开 `http://127.0.0.1:8000/`。再次双击会复用当前服务。浏览器书签也能打开已运行的服务，直接双击 HTML 文件则不能启动服务。

## 阅读、实验与练习

从导论进入，按目录阅读第 1 篇。正文页用解释、公式、手算和图形完成讲授；右侧是本节内容导航，左侧篇章目录可以隐藏或调整宽度。

点击“打开 JupyterLab 实验”，新标签页会打开原 Notebook。首次启动稍慢，页面会显示连接状态。内核显示为“Python · 动手学系统科学”，来自项目的 `.venv`。从上到下运行，然后修改参数、比较结果。Notebook 顶部和末尾均可返回本节讲解。

练习在网页作答。选择题提交后显示解析；代码题可先试算，再提交判定。学习进度按题目身份与版本保存。导论与第 1—15 篇共 182 节在网页阅读、在 Notebook 实验；第 16—17 篇暂时在 Notebook 内阅读完整教学，也可从网页目录用 JupyterLab 打开。

## 保存与结束

Notebook 的修改保存在原文件中，关闭前使用 JupyterLab 的保存按钮或 Ctrl+S。作答记录位于 `.local/learning/`，备份时可单独复制此目录；它不上传 Git。

关闭浏览器不会停止后台服务。结束当前学习会话可在项目根目录运行：

```powershell
.\.venv\Scripts\python.exe tools/start_course.py --stop
```

这会关闭教材服务及它启动的 JupyterLab，请先保存 Notebook。也可在终端前台运行 `python tools/serve.py`，结束时按 Ctrl+C。

## 移动项目与排查

启动脚本从自身位置查找项目。同一台电脑移动项目后，从新位置双击入口；跨电脑复制时重新创建 `.venv` 并安装依赖，不搬用旧虚拟环境。

| 现象 | 处理 |
|---|---|
| 未找到项目环境 | 在项目根目录执行安装命令 |
| 8000 端口被其他程序占用 | 先关闭占用服务，再启动教材；入口不会接管其他项目 |
| 网页不能连接 | 重新双击 `开始学习.cmd`，查看 `.local/service.log` |
| 实验启动失败 | 确认已安装 `[learn]` 依赖，点击重试；详情见 `.local/jupyter/server.log` |
| 公式、图形或导航显示异常 | 刷新当前网页；向维护者提供地址与浏览器错误 |

只为学习不需要安装 VS Code。JupyterLab 和判题均在本机运行，安装完成后，常规教学资源可离线使用。
