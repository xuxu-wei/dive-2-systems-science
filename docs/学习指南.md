# 学习指南

先按 [README 的安装说明](../README.md#run-m1)准备环境，再从[导论 Notebook 目录](../notebooks/00-导论/README.md)开始，接着进入[第 1 篇](../notebooks/01-看见系统/README.md)按顺序学习。Notebook 是完整教学入口，练习和可视化是它的配套入口。后续按全书篇章顺序继续，各篇入口与当前交付状态见 [README](../README.md#当前状态)。

## 在 Notebook 中学习

在支持 Notebook 的 IDE 中打开文件，选择项目 `.venv` 的 Python 内核，按顺序运行单元格。需要检查自己的修改时，重启内核并运行全部单元格；每节的代码都可单独运行。遇到环境或安装问题回到 README，不需要在每一节重新安装。

正文中的 Python 代码可以修改；图中 `Amount` 表示总量，`Time` 表示时间。图轴上的 U 与 T 是教学单位，具体含义和假设在各节正文中说明。

## 打开可视化与练习

在项目根目录双击[开始学习.cmd](../开始学习.cmd)，程序会检查本机服务并打开首页。使用 VS Code 时，第一次打开受信任的项目工作区，允许“自动任务”；以后打开工作区会自动检查服务。直接在其他 IDE 中打开单本 Notebook，按顺序运行单元格后也会检查服务。若尚未运行单元格，或关闭 Notebook 内核后继续使用网页，可使用根目录入口。

- [概念可视化](http://127.0.0.1:8000/chapters/02-04-数值模拟、误差与迁移/explore/)：以 2.4 为例，比较连续解析解与数值步长造成的偏差；其他探索页从对应章进入。
- [单元练习](http://127.0.0.1:8000/chapters/02-04-数值模拟、误差与迁移/practice/)：选择题提交后查看逐项解析；代码题可用示例试算或提交完整判定。每节 Notebook 也有指向具体题目的链接。

点击这些 HTTP 链接应显示网页；不要把项目中的 HTML 源文件当作教材阅读入口。如果显示源码，先核对打开的是否为以上本机地址。连接失败时重新打开根目录入口；它会复用可用的服务，或在教材更新、服务用户或 Windows 会话不一致时安全重启旧服务；正在判题时请等待提交完成后再试。

网页中的“在默认 IDE 中复习本节”通过系统的 `.ipynb` 文件关联打开 Notebook 原文件。Windows 文件关联调用失败时会尝试已安装的 VS Code，不修改你的默认应用。如果仍失败，页面会说明实际原因；请从当前桌面重新运行根目录“开始学习.cmd”，详细诊断在 `.local/service.log`。提示“已请求”只表示启动请求被接受，打开后仍需在 IDE 选择内核。

## 保存练习与复习

代码草稿保存在当前浏览器。正式作答记录保存在本机 `.local/learning/`，不会同步到 Git；样例通过不计入正式通过。刷新或返回题目后可继续编辑，旧判定仍对应提交时的代码或选项。

选择题只有单选和多选；计算题按题面返回指定数据。题面中的解释、预测和迁移能力通过选项辨析或代码结果核验，无需上传自由报告。

## 目录、进度和代码编辑

从[全书目录](http://127.0.0.1:8000/catalog/)按篇章跳转。全书按“导论 + 17 篇、85 章”导航；先读导论可认识全书的问题和方法，正式篇章沿原顺序学习。页面自动展开当前目录，章内用“本章导览 / 可视化与探索 / 练习”切换；没有额外可视化的章节只显示导览和练习。

首页中央黑洞是“00 · 导论”。单击或 Tab 选择，双击、Enter 或滚轮放大进入三个小节；小节卡片提供学习、自测入口，第三节还有可视化。卡片左右按钮在导论与第 1—17 篇之间首尾循环；滚轮缩小返回全景，在小节视图中滚轮不会打开 IDE。

导论三个小节各有三道选择题，自测通过数单独显示；不设通关门槛，也不并入各篇综合成绩。

灰色是未开始，橙色是进行中，浅蓝色是全部题目完整通过；进度按已发布题目及篇末题组汇总，规划页和阅读行为不增加完成状态。第 4、6 篇新版综合已覆盖各自六章；改题后按新版本计分，旧提交保留为历史，未改题目的同版本成绩继续有效。样章历史记录保留在本地，不计入正式课程进度。

练习按小节和题目标题选择。编辑代码时，Tab 插入四个空格，Shift+Tab 取消缩进，Enter 延续当前缩进；先按 Esc 再按 Tab 可把焦点移出编辑器。输入输出示例默认折叠，用于说明函数如何接收、返回数据。先“用示例试算”，再“提交判定”；仅通过示例不表示整题完成。

## 环境与已有虚拟环境

`.venv` 只有执行 README 的学习依赖安装后，才包含当前已交付内容需要的包；新篇引入依赖时按说明更新，不承诺预装未来全书环境。各阶段的验证环境见 ROADMAP 对应证据，已保存的依赖快照为 [constraints.txt](../tools/constraints.txt)。需要复现该组合时，可在安装命令末尾加 `-c tools/constraints.txt`。

VS Code 的终端解释器和 Notebook 内核分别选择；其他本地虚拟环境不会因打开本工作区而消失。解释器列表未显示时，使用“Python: Select Interpreter → Enter interpreter path”选择它的 `python.exe`；Notebook 右上角使用“Select Kernel → Python Environments”选择对应环境，并确保该环境安装了 ipykernel。未找到环境不等于需要重新创建或删除环境。新版 Python Environments 扩展也可通过用户级 `python-envs.globalSearchPaths` 添加工作区外的环境目录，再刷新环境管理器；具体入口见 [VS Code 环境说明](https://code.visualstudio.com/docs/python/environments)与[内核选择说明](https://code.visualstudio.com/docs/datascience/jupyter-kernel-management)。

深浅主题在全站保持一致。首页“暂停动效”同时暂停背景与天体；系统启用减少动态效果时采用静态呈现。教学可视化仍使用各自的播放按钮。
