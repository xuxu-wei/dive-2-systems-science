# 工程设计

## 内容职责

| 位置 | 职责 |
|---|---|
| `lessons/` | 已迁移课程的完整讲授 Markdown，包含定义、直观解释、推导和结果解读 |
| `notebooks/` | 可运行实验；第 6—17 篇在迁移前仍保留完整教学 |
| `exercises/` | 题面、答案与判题用例的唯一来源 |
| `web/reading/` | 生成的讲授页、实验图形及阅读界面 |
| `web/course/`、`web/home/` | 课程目录与知识星图 |
| `web/*/` | 各主题的交互探索及共用练习界面 |
| `src/systems_science/` | 绘图辅助、本机服务和 JupyterLab 管理 |
| `.local/`、`.work/` | 本机记录、日志与检查产物，不纳入 Git |

每个已迁移课节在 `notebooks/<篇>/catalog.json` 中指向讲授文件。正文按讲解需要选择材料：`<!-- experiment: 单元格ID figure -->` 只引用该单元的图，不带入代码或打印；确需解释算法时才显式使用 `code` 或写出短代码示例。正文无需引用全部实验单元。中文 Markdown 使用保留公式的渲染器，并支持英文括注后紧接中文的粗体。修改算法后更新对应实验结果，再重新构建网页，避免维护两套实现。

## 构建与运行

维护者安装 `[learn,dev]` 后运行：

```powershell
.\.venv\Scripts\python.exe tools/build_lessons.py
```

这一命令依次生成课程目录、知识星图和已迁移讲授页。目录的公开重难点来自大纲的“教学重难点”；不发布维护用的核验答案，也不自动插入英文术语括注。星图校验基于 JSON 内容，忽略换行格式；过期时服务用当前目录重新计算响应。

`开始学习.cmd` 通过相对位置调用 `tools/start_course.py`。教材服务绑定回环地址 8000，提供网页与原判题接口。普通 HTML 不具备启动 Python 服务的权限，因此保留一次点击的本机启动程序。

点击实验链接先同步打开 `/notebook/?id=...` 新标签页，再由该页请求受同源令牌保护的 `POST /api/notebooks/open`。服务只接受目录内的 ID，启动或复用自己的 JupyterLab，以随机本机端口和认证令牌连接；每次打开分配独立 Lab 工作区。Notebook 路径以项目位置解析，内核固定为项目环境。JupyterLab 的设置与工作区保存在本项目 `.local/jupyter/`，初始配置关闭新闻和更新提示。关闭教材服务时一并回收本次启动的 Lab。

实现参考同目录下《动手学系统辨识》的 Notebook 启动流程，并依照 [JupyterLab 文件链接](https://jupyterlab.readthedocs.io/en/stable/user/urls.html)与 [Jupyter Server 认证](https://jupyter-server.readthedocs.io/en/latest/operators/security.html)保留本机访问认证。公式使用本地 KaTeX，版本与许可见 `web/vendor/katex/`。

## 维护核对

正文按课节连读，检查公式、示例、实验输出和解释的对应。运行范围以修改的实验为准；检查 JupyterLab 实际打开原文件、重试、目录移动、星图过期与深链接刷新。迁移不改变题目 ID、版本或判题契约，个人学习记录保持原位。
